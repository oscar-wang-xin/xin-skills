## 萃取文风规范

### 1. 叙事视角

第三人称限知，主视角紧追陈平安（前 20 章约占七成篇幅），辅以年轻道人、苻南华、黑衣少女（宁姚）、宋集薪等少数视角人物；视角切换以章节/场景为界，不频繁跳切。内心活动几乎不用「心想 / 心中」标签（心想 4 次 / 0.2 章、心中 6 次 / 0.3 章），改为「陈平安觉得 / 陈平安心想」直述，或用动作、神态外化（如「陈平安猛然转过身，背对着道人，扬起拳头挥了挥」）。「只见」6 次 / 0.3 章，亦属低频。整体是「贴着人物走」的限知，不是全知上帝旁白。

### 2. 句式特征

中等偏长句，逗号连缀绵密：平均段长 51.9 字（中位数 34；≤20 字段占 27.5%、21–50 字段占 41%、51–100 占 20%、101–200 占 7.7%、201–400 占 3.6%、>400 仅 0.1%），平均句长 43.2 字（以 。！？； 切分，共 2015 句），逗号密度 74.7 / 千字（极高），句号 17.2 / 千字，顿号仅 1.1 / 千字。招牌手法是**极短句收束**：章末或段末常砸一句三五行以内的短句制造留白或反差（「骄傲的少女。/ 乖巧的飞剑。」「全然不像是一个将死之人。」「这位老龙城少主，头脑一片空白。」）。破折号在本样本为 0（版本归一化，见样本说明），仿写按标准标点；省略号 `……` 保留且常用（91 次）。

### 3. 对话体系

对话占比高（32.9%，788 句台词，高于多数网文），平均台词 37.1 字、中位数 18 字；含引号段落占 46.6%，纯对话独立成段仅 20 段 = 1.2%（<3%），是「一段内多人来回」结构，写时**禁止**网文式「一句一段」。对话标签极集中：「道」占 66%（道 518 / 笑道 90 / 问道 89 / 说道 53 / 喝道 4 / 怒道 3），偶用「言道 / 喊道 / 高声道」，基本不用「说」单字标签。台词短而密，且大量承载「讲道理 / 说理」功能（少年与道人、儒士辩理），是剑来区别于爽文的标志。对话嵌在叙事段内，常带动作神态（「神色郁郁道」「放低嗓音」「坦然笑道」）。

### 4. 叙事节奏

慢热、市井日常铺陈为主，冲突稀疏而克制；时间跨度极小（前 20 章集中于泥瓶巷与小镇数日），过渡词低频（当下 8 / 原来 13 / 片刻 17 / 跟着 10 / 随即 4）。不靠密集爽点推进，而靠「人物在困顿中守心、讲理」的绵柔张力蓄势；偶发冲突（飞剑掠过、刺杀、赌斗）短促收束，不拉长打斗。日常描写占比高但非冗余（陈平安讨债、烧瓷、拉坯等细节构成烟火气）。

### 5. 词汇与修辞

纯现代白话 / 口语为底，**零古体词**：看 251 : 瞧 9、没有 146 : 未曾 2、什么 120 : 甚么 0、知道 65 : 知晓 6、已经 70 : 已然 0、突然 52 : 陡然 0、如果 48 : 倘若 0、这么 34 : 恁地 0 / 怎地 0、别 56 : 休得 0、兀自 0、便即 0、须得 0——古体词（未曾 / 甚么 / 陡然 / 兀自 / 休得 / 恁地 / 怎地 / 便即 / 须得）全 0 或近 0。点缀文雅虚词：便 91 / 即 24（作「文气」修饰，用量少于《将夜》）、如此 39 : 这样 15（轻度偏好「如此」）、当下 8 : 这时 1（8:1 偏好「当下」）。罢 23 : 吧 43 两者皆可。比喻标记：一般 17 / 如同 9 / 好似 8 / 似的 7 / 宛如 2 / 犹如 1 / 便如 2；善用**拟物 / 拟人冷幽默**（飞剑「病恹恹的，像是在嫌弃年轻道人」、少女「骄傲的」、飞剑「乖巧的」）。拟声：哈哈 10 / 呵呵 3（角色笑声）。高频人物词：陈平安 / 宋集薪 / 苻南华 / 刘羡阳 / 蔡金简 / 稚圭 / 顾粲 / 齐先生；少年 367 / 少女 183 / 老人 178 / 孩子 123——少年成长 + 市井群像。

### 6. 情绪基调

文艺温润 + 市井烟火 + 冷幽默 + 哲理。爽感不来自升级爆点，而来自「贫贱少年在困顿中守心、讲理、不失体面」的绵柔力量（「与脚下蝼蚁，讲甚道理？」「天雨虽宽不润无根之草」）。幽默是反差式、不张扬（「狗屎。」「骄傲的少女。/ 乖巧的飞剑。」）。情绪曲线：日常烟火 → 微小冲突 → 意象留白或哲理收束，极少大起大落。对「讲道理 / 读书做人」有持续温情凝视（齐先生站在门口「恍若神人」）。

### 7. 章节钩子写法

章末钩子偏**意象留白 / 哲理冷峻 / 反差幽默 / 反转留白**四类，非强悬念爆点：

- 意象留白：「只见那位先生始终站在门口，身影沐浴在阳光中，远远望去，恍若神人。」「搁置在屋内桌面上的鞘内飞剑，骤然嘶鸣。」
- 哲理冷峻：「与脚下蝼蚁，讲甚道理？」「天雨虽宽不润无根之草，记住哦。」「修行路上，术法无边，神通无穷。理有大小，道有高低。」
- 反差幽默：「少年放低嗓音，"狗屎。"」/「骄傲的少女。/ 乖巧的飞剑。」
- 反转留白：「全然不像是一个将死之人。」「原来少年的后背并无半点泥屑。」

常以一个极短句或一句问句收尾，余味而非断崖。

### 8. 环境描写

极简，纯景物段仅 0.7%（12 / 1653），字数占比 3.0%。质感不靠形容词堆砌，而靠具体器物 / 地名 / 声响透出：泥瓶巷、铁锁井、桃枝、草鞋、铜钱、青石板、杏花巷、牌坊楼「气冲斗牛」匾额。环境常作为人物动作的舞台，不独立成段抒情。

### 9. 行文禁忌

系统流界面词全 0（系统 0 / 宿主 0 / 任务 0 / 面板 0 / 升级 0），说书套语全 0（要知后事 0 / 列位看官 0 / 且听下回 0），网文套语极低（不由自主 1 / 这一刻 4 / 内心深处 4）。修仙本体词「境界」5 /「丹田」0 属正文核心（仙侠设定），**不禁**——区分「修仙本体词」与「系统流界面词」，后者禁、前者不禁。word_pairs 的 A 类（说话 / 何况 / 何不 / 不该 / 一晃 / 甚是）绝对频次均 ≤9 且分母为 0，比值失真，**不取为硬规则**；真实语感由 B 类「现代体压倒」决定（见维度 5）。

### 10. 开篇习惯

几乎全以**人物动作 / 场景切入**，极少环境铺陈：陈平安起床（「天微微亮，尚未鸡鸣，陈平安就已经起床」）、道人推车、少女走向小巷、苻南华端坐……切入快、无冗长前奏。偶以节令 / 器物 / 环境起笔亦自然（「二月二，龙抬头。」「小镇不大不小，六百多户人家」「杏花巷有口水井，名叫铁锁井」）。前 120 字即有人物在动，不空写景。

## 段落与句式约束

1. 段落以中长段为主（30–60 字常见），避免一句一段；对话可嵌在叙事段内来回，纯对话独立成段控制在极低比例。
2. 多用逗号连缀铺陈，句长中等偏长（30–50 字常见），但章末 / 段末允许砸极短句（三五字到十数字）制造留白或反差。
3. 标点按标准书写：引号成对、省略号 `……` 可用、破折号 `——` 可按需使用（本样本被归一化删除，不代表禁用）；顿号少用、多用逗号。
4. 杜绝大段密集长段落，杜绝书面化书面腔。

## 对话写作规范

1. 角色台词偏短而密，常承载「讲道理 / 说理」功能；少年口吻质朴、市井、认死理。
2. 动作神态紧贴台词（「神色郁郁道」「放低嗓音」「坦然笑道」「猛然身体僵硬」），不孤立写台词。
3. 对话节奏：一段内可多轮来回，台词中位约 18 字，长理辩可至数十字但不拖沓。
4. 对话标签用「道 / 笑道 / 问道 / 说道」为主，避免单字「说」；喜怒用「怒道 / 喝道 / 高声道」等变体。

## 环境描写规范

1. 描写密度上限极低：单章纯景物段不超过 1–2 段，不独立成抒情段。
2. 手法偏好：用具名器物 / 地名 / 声响透出质感（泥瓶巷、铁锁井、桃枝、青石板），不堆形容词。
3. 位置规则：环境服务于人物动作，作为舞台而非主角。

## 章节钩子规范

1. 末尾悬念类型偏好：意象留白 / 哲理冷峻 / 反差幽默 / 反转留白，四选其一，非强悬念爆点。
2. 末尾句式特征：常以一句极短句或一个哲理问句收尾（「……讲甚道理？」「全然不像是一个将死之人。」）。
3. 与下章衔接方式：留余味、埋小钩，不写「欲知后事」式说书套语。

## 开篇规范

1. 开篇切入方式：人物动作 / 场景直入，快切无冗长前奏。
2. 开篇句式偏好：可节令起笔（「二月二，龙抬头。」）或人物动作起笔，前 120 字内必有人物在动。
3. 前 200 字信息密度：直接铺人物与当下处境，不空写景、不旁白铺垫。

## 叙事节奏规范

1. 冲突切入速度：慢热，日常烟火铺垫为主，冲突稀疏克制、短促收束。
2. 铺垫方式：以市井细节（讨债、烧瓷、拉坯）蓄势，不靠信息轰炸。
3. 日常描写占比上限：可高，但须服务于人物烟火气，不注水。
4. 信息释放节奏：绵柔蓄势，靠人物守心 / 讲理释放张力。

## 词汇修辞规范

1. 允许使用的高频词汇清单：现代白话词（看 / 没有 / 什么 / 知道 / 已经 / 突然 / 如果 / 这么 / 别）；点缀文雅虚词（便 / 即 / 如此 / 当下）；少年 / 少女 / 老人 / 孩子等人物群像词。

## 情绪基调规范

1. 整体调性定位：文艺温润 + 市井烟火 + 冷幽默 + 哲理，非升级爽文。
