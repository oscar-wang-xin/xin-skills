# 《赤心巡天》文风范例（节选自前20章纯净样本）

> 以下片段均取自清洗后的正文，已剥离章末作者按与「(本章完)」标记。直角引号「」与俗体「什幺」均保留原书用法，供仿写对标。

## 一、开篇意象铺陈（第1章）
太阳悬在高天，将它的光和热，不偏不倚洒落人间。不分老幼，不辨贵贱。大爱如无情。
幼鹿涉溪时，飞鸟穿于林。
起先只能看到天边亮起一个暗红光点，眨眼迫近。
焰尾连成一道火线，如神人挥笔，划破长空。
庄国数千里山河几乎被这道火线一燎而过，忽地一道黑光冲霄而起，拦路于前。

> 特征：首句即意象，短句堆叠（多≤20字），靠逗号切分意群；比喻用"如"（如神人挥笔）；不写套话前奏。

## 二、概念切入 + 设定自然带出（第2章）
道脉是修行的基础。
这个「道」，不是道门的道，而是大道的道。无论释道儒、兵法墨又或其他什幺流派的修者，都必以显现道脉为修行第一途。
在远古时代，所谓的修行种子，便是天生道脉自显之辈。但人族并不以天赋定终生，开脉丹便是解决修行资质的方法之一。

> 特征：首句直接讲设定，不另起"设定说明"段；世界观借叙述带出；俗体"什幺"统一使用。

## 三、冲突快切 + 极简对话标签（第4章）
姜望话音方落，毫不犹豫拔剑便斩。
「什、什幺！？」
寒光乍现，方鹏举连滚带爬避开这一剑，惊怒之极，也狼狈之极。
除此之外，在场竟无一人反应过来。几乎所有人都以为下一幕会是兄弟和解，情义深重，甚至传为一时佳话。
谁也没有想到，有众人瞩目，兄弟之情裹挟，姜望竟还真的会出剑！
「鹏举。」姜望嘴角含笑地看着他，但那笑容却格外冰冷，「说好的引颈待戮，你怎幺躲了？」

> 特征：开篇即落刀，无缓冲；对话标签压倒性用"X道："；台词短、有棱角、带情绪；突变用"寒光乍现"等短句。

## 四、动作/异变场面排比造势（第8章）
木椅生枝，木窗张爪，巨树破土，荆棘乱舞！
整座枫林道院在瞬息之间，就在夜幕下变成了一座碧色的囚笼！

> 特征：四字/短句排比制造视觉冲击；环境为动作服务，不白描；「」收尾抛意象悬念（章末钩子之一类）。

## 五、沉郁悲悯 + 短句爆发（第15章）
目光往上，他于是理所当然地看到了这个家庭里的最后一副白骨。
小小的、纤细的、脆弱的，孤独无助的骨架。
那是一个曾被父母视若珍宝的小女孩，在这世上唯一的留存。
他感到愤怒。
无法抑制、无比暴烈的，愤怒。

> 特征：情绪克制铺垫后用极短句炸开；用"小小的、纤细的、脆弱的"列锦收束；章末钩子以陈述短句抛情绪。

## 六、克制态度 + 对白收尾钩子（第7章）
他抱着方鹏举的尸体，转身离开了。
从头到尾，没有看那些刀币一眼。
这就是凌河的态度。

> 特征：不直抒"凌河很讲义气"，用动作+一句判断收束；章末钩子之一类（陈述短句抛人物态度）。

## 七、哲思短句钩子（第7章章末原句）
迎接嘲笑最好的方式是什幺？我们不迎接它，我们抛弃它。

> 特征：章末钩子三类之一——哲思反问短句，不用"欲知后事"套语；俗体"什幺"。

## 八、对白未竟钩子（第3章章末）
「但既然鹏举你这幺说了……」只听见姜望缓缓说道：「那三哥就，恭敬不如从命！」

> 特征：章末钩子三类之一——对白反差/未竟，表面顺从实则决裂；「」直角引号收尾。

### 仿写自检清单
- [ ] 用第三人称限知，叙述者隐身，不破壁直呼读者
- [ ] 段长多≤50字，句长约25字，高频逗号断句
- [ ] 对白一律「」直角引号，标签压倒性用"X道："
- [ ] 对话占比约20%，叙事主导
- [ ] 俗体"什幺"统一，不写"什么"
- [ ] 无系统流/升级流界面词、无说书人套语、无大段环境白描
- [ ] 章末钩子用「对白未竟 / 哲思短句 / 意象暴力悬念」三类之一
- [ ] 情绪沉郁克制，爆发用短句，不灌鸡汤
