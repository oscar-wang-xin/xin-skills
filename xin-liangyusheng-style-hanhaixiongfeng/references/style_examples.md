## 1. 开篇习惯：第 1 回词开路 + 大漠景语（全书仅此一次）

```
紫塞黄云望眼遮，征鞑未解又天涯，可堪绿鬓斗霜华。　[错字] 征鞑→征鞍
剩水残山思故国，荒沙瀚海乏仙槎，豪情犹在莫兴嗟。
——调寄浣溪沙
漠漠黄沙，骄阳似火。这正是蒙古库里戈壁上最炎热的季节，七月里的某一天的中午时候。
大地都好似喘不过气来，在这万里无垠的大沙漠上，一切都好似静止了，看不到什么有生命的东西，只偶尔可以看见沙石堆中绽出的几根野草。
没有静止的只有流沙。一阵狂风过后，流沙四散，俨若惊涛。
```

要点：词三行 + `——调寄浣溪沙` + 拟人化景语（`大地都好似喘不过气来`）+ `俨若惊涛` 式比喻。第 2 回起零前奏。

## 2. 开篇习惯：第 2–20 回直接承接

```
李思南喜道：“孟大侠知道家父？”孟少刚道：“我好似听人说过这个名字。”
```
```
李思南给柳三娘接连打了三鞭，打得他头昏眼花，百骸欲散，眼看看宋铁轮的双轮又已推压过来，李思南毫无招架之力，唯有闭目待死，哪知就在他摇摇欲坠之际，忽觉身子一轻，已是给人抱了起来。
```

要点：对话句 / 动作句起手，`哪知……之际，忽觉……` 是危机续接的标准句型。

## 5. 对话体系：段首「人名＋道：」推进 + 自嘲式自报家门

```
“请恕冒眯，我一直放心不下，只怕姑娘脱不了险。姑娘，你无恙么？”　[错字] 冒眯→冒昧
杨婉好生诧异，道：“你是谁？”

```

要点：段首直接 `人名＋道：`；幽默只藏在人物自嘲里。

## 6. 对话体系：动作神态嵌标签

```
明慧公主又惊又喜，紧握着杨婉的手说道：“果然是你！你怎么会到这儿来的？”
```
```
孟少刚低头一看，面色微微一变，但转瞬便即恢复如常，不让李思南看出，淡淡说道：“哦，是李希浩吗？”
```

要点：`又惊又喜，紧握着……说道`／`面色微微一变，但转瞬便即恢复如常`——神态先行、标签居中。

## 7. 对话体系：蒙古人物的口吻

```
拖雷与明慧公主走近金帐，刚好听见成吉思汗在帐中骂人：“哼，说什么多行仁义，少施杀戮，这不过是腐儒之见，迂拙之言！我若不把敌人杀得胆寒，焉能使四方慑服？
```

要点：`哼／焉能／慑服`——霸直露的历史人物腔。蒙古称谓（安答／大汗／金帐）进台词。

## 11. 歌谣整段嵌入（本书独有的大件）

```
其中一个少女，长得十分美丽，抱着马头琴唱道：
“大风卷起了黄沙，
天边的兀鹰盘旋欲下；
哥呀，你就是天边的那只兀鹰，
你虽然不怕风沙，你也不要下来呀！
……
我要乘风来找你回家！”
琴韵悠扬，歌喉婉转，李思南不禁也听得痴。
```

要点：每行独立成段、以 `"` 开头跨段不闭合，唱完才收 `"`；歌完一句感受（`听得痴了`）拉回叙事。

## 12. 跨段台词（原书排版特征，可少量照用）

```
红衣喇嘛道：“这小子虽然不是怎么了，但赤老温，你也不可轻敌了。
这是蒙古特有中土所无的‘金弓十八打”的招数。蒙古人长于骑马射箭，弓箭是他们最常用的武器。
```

要点：说话人标签段开引不闭合、次段续台词；正常段仍按标准配对。

## 13. 情绪段：克制写悲

```
往事一幕幕的从心头翻过，屠凤手按挂在马鞑上的骨灰袋，眼泪盈眶，凄怆欲绝。她在火化龙刚的时候没有掉下一滴眼泪，如今却是不由得哭出来了。　[错字] 马鞑→马鞍
```
```
明慧公主在挂念她，她则在挂念李思南。“南哥不知已经逃了出来没有？人海茫茫，却到哪里寻找他呢？”杨婉心想。
```

要点：哭有节制（先忍后溃）、心理用自由间接引语；骨灰袋、火化——本书的生离死别浓度高于前作。

## 14. 环境描写：借人物引诗 + 风物即注

```
李思南想起了读过的诗：“天苍苍，地茫茫，风吹草低见牛羊。”时节是盛夏的七月，野草没有他想象的得那么高，在草原与戈壁的接壤之处，也未曾发现一群群的牛羊。
```

要点：写景挂人物（想起诗→对照眼前），一段即收；全书纯景物段仅 0.3%。

## 15. 回末钩子：三层定式（`正是：` 挂正文段尾）

```
……拿起筷子，在地上写了三个工笔揩书。孟少刚低头一看，面色微微一变，但转瞬便即恢复如常，不让李思南看出，淡淡说道：“哦，是李希浩吗？”正是：
言者无心听有意，险教碧血染黄沙。
欲知后事如何？请听下回分解。
```
```
李思南上前道谢，那汉子笑道：“我也要多谢你呢，不是你先耗了他气力，我未必打得过他。李公子，你应该知道我是谁吧？”正是：
探求身世隐，荒谷访奇人。
欲知后事如何？请听下回分解。
```
```
明慧公主在挂念她，她则在挂念李思南。“南哥不知已经逃了出来没有？人海茫茫，却到哪里寻找他呢？”杨婉心想。正是：
人海茫茫何处觅？为君一日九回肠。
欲知后事如何？请听下回分解。
```

要点：`正是：` 紧挂正文段尾（**不独占一段**）；对句 7+7 为主（例 2 是 5+5 变格）、可带问号（例 3）；套语纯用"请听"。

## 16. 转场词实录

```
且说屠凤、孟明霞二人正在吃紧，忽见新来的这队敌人之中，竟有李思南和杨婉在内，都是大为惊诧。
```
```
在路上过了七天，终于到了和林。李思南怀着惴惴不安的心情，给他们带到一座帐幕。
```

要点：`且说`（9）／`再说`（27）／`第二天`（15）／`转眼`（10）／`过了七天`式里程句；**"次日""却说"零出现**。
