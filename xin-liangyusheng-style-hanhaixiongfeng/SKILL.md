## 萃取文风规范

### 1. 叙事视角

- **第三人称全知，双主公交替**。视点主要落在李思南、杨婉之间，随场景移交；蒙古一侧的成吉思汗、拖雷、明慧公主视点穿插。前 20 回视点依次为李思南 → 李思南/杨婉 → 屠凤 → 杨婉 → 孟明霞，每回 1–3 个视点。
- **叙述者随时插注解释，但内容是"名物考据"而非人物代称**。这是本书夹注与前作不同的地方——样本 `（）` 12 处**全是蒙语、官制、习俗注释**：`（宋宁宗开禧二年，公元一二0六年）`、`（相当于参谋之类的“师爷”）`、`（“哈达”即手帕，蒙古和西藏的习俗，送哈达即是表示友谊）`、`（蒙语‘库里尔泰’是‘各个有权力的人’的意思。）`、`（民间习俗，孝子守灵七七四十九天，是谓“满七”）`。**没有一处"拙著"式跨书互文**（样本 0 处）。
- **心理活动用"心里想道"直接引出**，是全书最密集的视角标记：心里想 104（5.2 次/章）、心中 99、心想 54、心道 21、暗自 22、寻思 4。长段内心独白偶见（屠凤火化龙刚、杨婉挂念李思南），但都由"想道"领起、引号内进行。
- **感官引导词**：只见 89（4.5 次/章）、只听 52、忽听 41、但见 6。
- 绝不使用第一人称叙述段（歌谣、词曲引文除外），不使用"我"作为叙述主语。

### 2. 句式特征

- **中短段落为主，对话织进叙述**。平均段长 68.3 字，中位 61，分布：21–50 字 29.7%、51–100 字 43.5%、101–200 字 17.7%、201 字以上仅 0.6%。一段通常走「叙述 + 一次发言」或「叙述 + 动作」两层。
- **平均句长 30.5 字**（以 `。！？；` 切分，6,860 句），逗号层层递进（`，` 密度 62.1/千字，是句号的 2.8 倍——八本中最低的逗/句比，句子比前期作品干脆）。
- **标点密度（每千字）**：`，` 62.1、`。` 21.9、`：` 11.8、`？` 5.6、`！` 4.1、`、` 0.8、`；` 0.3。
- **省略号 27 处（0.1/千字）、破折号 41 处（0.2/千字）**，两者都极稀疏。省略号只用于台词中断（`这位姑娘的遭遇其惨！……`）；破折号用于歌谣领起（`“我的万众圣主——`）与同位语。**段首绝不用破折号**（样本 0 处）。
- **段落末字符分布**：`”` 1,743 段、`。` 1,160 段、`！` 72 段、`：` 28 段、`，` 27 段。**段末 `，` 的 27 段全部是歌谣/民歌的跨段行**（`“大风卷起了黄沙，`、`哥呀，你就是天边的那只兀鹰，`），是原书排版特征，可照用：歌词每行独立成段、以 `"` 开头，整段歌谣唱完才收 `"`。
- **引号体系**：当前对白用全角双引号 `“”`；**单引号 `‘’` 97 组专用于"双引号台词/夹注内层引用的专名、术语、引文"**——`‘瀚海’`、`‘思南’`、`‘神翼营’`、`‘撼山易，撼岳家军难’`、`‘惊鸿照影’`。**与《江湖三女侠》的"单引号=回忆旧话"完全不同，这里是引号嵌套的内层**。样本 97 组中 93 组都在双引号内。
- **跨段台词**：说话人标签段以 `“` 开引、台词跨段续行，样本 61 段开多、23 段收多（`红衣喇嘛道：“这小子虽然不是怎么了，但赤老温，你也不可轻敌了。`⏎`这是蒙古特有中土所无的‘金弓十八打”的招数。`）。仿写可少量照用，正常段仍按标准配对。
- 直角引号 `「」`、方括号 `【】`、波浪号一律不用（样本为 0）。

### 3. 对话体系

- **对话占比 40.2%，为梁羽生八本对照中最高**（龙虎斗京华 31%、江湖三女侠 26%）。台词 3,083 句，平均 28.2 字，中位 20 字。
- **含引号段 79.9%**（2,455/3,072 段）。**纯对话独立成段仅 39 段 = 1.3%**（其中相当部分是歌谣与短促喝叫）。**这是本书最硬的规范：严禁网文式"一句一段"的对话排版。**
- 段落构成：纯叙事段 34.5%、**含 1 处发言 58.5%**、含 2 处以上发言 7.1%。本书的主流段型是「叙述/动作 + 一人发言」的一段一体式，与《江湖三女侠》"近半段落多人来回"不同——**多人对答通常各自成段、交替推进**，但每段仍带叙述成分。
- **说话标签**：`道：` 2,310 处（占全部标签 **69%**）、`说道` 689、`笑道` 274、`喝道` 93、`叫道` 93、`问道` 47、`怒道` 26、`奇道` 1。**`道：` : `说道` = 3.35 : 1**，写法永远是"人名＋道：＋引号"。
- **段首直接以"人名＋道："起段**是对话推进的主力：`杨婉道：` 65 段、`屠凤道：` 37、`石璞道：` 25、`阿盖道：` 19、`拖雷道：` 17。台词前面常带一句对方反应作接榫。
- **动作神态嵌在标签前或发言后**：`面色一沉，说道`、`明慧公主又惊又喜，紧握着杨婉的手说道`、`把手一扬，一柄飞镖倏的飞了出来`。
- 蒙古人物的台词带草原口吻与称呼（安答、大汗、金帐）；成吉思汗的台词霸道直露（`我若不把敌人杀得胆寒，焉能使四方慑服？`）。

- **时间跳跃**：`第二天` 15、`转眼` 10、`且说` 9、`过得` 6、`一晃` 3；**`次日` 0 次、`却说` 0 次**——转场一律用"第二天／转眼／且说／再说"，别写"次日一早"。
- 武打段落节奏为"招名 + 兵器/身法 + 结果"循环，招名全加引号：`变作了“毒蛇吐信”的招数`、`把“金弓十八打”的招数使得变幻莫测`、`倏的一个“斜切藕”的招式斜削下来`、`使的是“枯藤缠树”的招数`。
- **歌谣整段嵌入是本书独有的大件**：蒙古少女抱马头琴唱情歌、成吉思军中长调，一次可占 9–11 行，唱完再回叙事（`琴韵悠扬，歌喉婉转，李思南不禁也听得痴`）。
- 日常过场（赶路、投宿、换马）一两句带过，立刻接事件。

### 6. 情绪基调

- **底色是苍凉悲壮的家国流离**：寻父、亡国、战乱、埋骨异乡（李思南祭父、屠凤火化龙刚、杨婉丧兄），悲情写得直白克制，哭有节制（`她在火化龙刚的时候没有掉下一滴眼泪，如今却是不由得哭出来了`）。
- **明亮笔触靠歌谣与草原风物**：卡洛丝的马头琴情歌、草原送别、明慧公主的天真痴情。**叙述者不抒情，情绪全部从人物与歌声里长出来**。
- **幽默稀薄**（对比《江湖三女侠》的少女娇嗔），只在杜雄自报名号（`木土杜，单名一个雄字，英雄的雄。但我只会几手三脚猫的功夫`）这类自嘲里露一点。禁用现代梗。
- **爽感来源**：武功见识折服对方（李思南箭术/剑法受成吉思汗赏识）、识破奸谋（假李希浩＝余一中）、以理折人。爽点由旁观者反应递出，不由主角自夸。

### 7. 章节钩子写法

- **20/20 回三层定式，`正是：` 挂在正文段尾**（不独占一段），对句与套语各自成段：

  ```
  （正文叙述在危机处收住，段尾接）……正是：
  言者无心听有意，险教碧血染黄沙。
  欲知后事如何？请听下回分解。
  ```

  第 3 回的变体：正文段直接接对句（`那“刺客”早已是鸿飞杳杳了，正是：` 之后换行对句），形制不变。
- **对句形制以七言为主**：18/20 回是 `7+7` 言（`万里远来甘认贼？飞刀留字起疑云。`、`画虎画皮难画骨，知人知面不知心。`、`山穷水尽疑无路，柳暗花明又一村。`——常借成句谚语），仅 2 回是 `5+5` 言（`探求身世隐，荒谷访奇人。`、`明知不是伴，情急且相随。`）。
- **第三行套语**：样本 `请听` 20 : `请看` 0，全本 59/60 回齐备（57 处标准句）。基准写法 **`欲知后事如何？请听下回分解。`**——本书纯用"请听"，与《侠骨丹心》一致，不要混入"请看"。样本第 20 回源本作 `欲如后事如何`（"如"为"知"之讹，见错字清单）。
- **悬念类型**：生离死别（`人海茫茫何处觅？为君一日九回肠。`）、奸谋未破（`画虎画皮难画骨`）、危机悬置（`谁知横祸又飞来`）。少用"欲知＋具体疑问"的变体（样本 0 处，全本亦少）。
- 回末定式前最后一段必须是**动作或对话**，不能是作者总结陈词。

  - 回 7：`李思南吃了一惊，说道：“爹，待你老人家病好了，那、那时也还不迟，何必这样匆促？”`
- **前 200 字必落地**：第一个 120 字内必须出现人物动作或对白（第 1 回的例外是"词 + 景语"开路，仅限首回）。
- 回内转场用 `再说`（27）、`第二天`（15）、`转眼`（10）、`且说`（9）、`当晚/这晚`（各 2）；**"次日""却话""翌日"零出现，别写**。

## 段落与句式约束

1. **段长按 40–90 汉字控制**（样本中位 61 是可信笔法值）；关键桥段允许 150–250 字长段（打斗、歌谣、心理）。
2. **每段承担 1–2 层信息**：本书主流是"叙述/动作 + 一次发言"的单层紧密段，不是《江湖三女侠》式的多层混装段；禁止单层平铺段连续出现。
3. **对话绝不单独成段**（本书仅 1.3%，且多为歌谣与喝叫），台词必须与标签、动作或叙述同段；多人对答可各自成段交替推进。
4. **句长基准 30 字**，逗号推进（逗号密度为句号的 2.8 倍）；一句内超过 4 个逗号应收句号。
5. **标点密度对齐**：`？` 5.6/千字、`！` 4.1/千字（本书问号多于感叹号，与多数武侠相反）；`、` 与 `；` 极罕见，并列词用逗号。
6. **省略号只用于台词中断（全篇 3 处以内）；破折号只用于歌谣领起与同位语（全篇 5 处以内）；段首不用破折号。**
7. 歌谣按原书排版：每行独立成段、以 `"` 开头不闭合，唱完一句才收 `"`；引出诗词书信的标签段以 `：` 收尾，内容另起一段。

## 对话写作规范

1. **台词中短**：平均 28 字、中位 20 字。一句台词不超过 50 字，超过就拆段。
2. **标签格式固定**：`（人名／她／他）＋（动作神态）＋道：＋“台词”`。`道：` 约七成，`说道/笑道/喝道/叫道` 为辅。
3. **段首可直接以"人名＋道："起段**推进对答（杨婉道：／屠凤道：），这是本书对话引擎。
4. **动作神态嵌在标签前后**：`冷冷说道`、`紧握着杨婉的手说道`、`把手一扬`。禁止"他说，带着愤怒的语气"式翻译腔。
5. **台词内引用专名、术语、成句一律用单引号**：`‘瀚海’`、`‘思南’`、`‘撼山易，撼岳家军难’`。当前对白用双引号，两层不可混。
6. 蒙古人物台词用 `安答／大汗／金帐` 等草原称谓；成吉思汗台词霸道直露；少女台词含蓄带情（明慧公主）。

## 环境描写规范

1. **密度上限**：景物段不超过全篇 1%（本书 0.3%，是八本最省的一本）；仅第 1 回可用整段景语铺场。
2. **手法**：以体感与拟人写（`大地都好似喘不过气来`），或借人物引诗（`天苍苍，地茫茫`），不写独立抒情段。
3. **位置**：场景转换、人物进入新地域（戈壁→和林→中原）时一笔带过；战斗与对话中不插写景。
4. 取景签名：大漠、草原、金帐、马头琴、哈达——**服务地域感与民族氛围，不渲染情绪**。

## 章节钩子规范

1. **三层定式，`正是：` 挂正文段尾**，对句与套语各成段：`……正是：` / 七言对句 / `欲知后事如何？请听下回分解。`
2. **对句以七言为主**（约九成），五言偶用；可用成句谚语（`画虎画皮难画骨，知人知面不知心`）；内容概括本回或点出悬念。
3. **定式前一段必须是动作或对白**，在离散/疑团/危机处收住。
4. 末回（大结局）不用套语，以对句加 `（全书完）` 收尾。

## 开篇规范

1. **首回可用词牌开路 + 整段景语**（全书仅第 1 回）；此后每回直接承接上文动作或对话，零前奏。
2. **开篇句式**：对话句或动作句起手；不写"话说""却说"（本书连"却说"都不用）。
3. **前 120 字内必须出现人物动作或对白**（首回除外），禁止格言、议论、抒情起手。

## 叙事节奏规范

1. **冲突切入**：每回开篇 200 字内进入事件；升级 2–3 次转折；武斗写足、日常跳过。
2. **铺垫**：只用"原来"做事后补叙（9.2 次/回）；身份谜团分批释放（假李希浩疑点 → 柏风谷真相）。
3. **动作接榫套语**：`说时迟，那时快`、`心念未已`、`想至此处`、`话犹未了`、`这刹那间`——写打斗与突发事件时优先使用。
4. **歌谣可整段嵌入**，一次 9–11 行，唱完回叙事；全书不超过 2–3 次。

## 情绪基调规范

1. **整体调性**：家国流离为底、儿女情长为线、草原歌谣为亮色。叙述者克制，不评判不抒情。
2. **每回情绪曲线**：承接余波 → 危机升级 → 生离死别或误会加深 → 定式钩子。
3. **幽默规则**：只放在人物自嘲与对答里（杜雄自报名号式），浓度远低于《江湖三女侠》；叙述者不抖机灵，不用现代梗。
4. **爽感来源**：武功见识服人、识破奸谋、以理折人；由旁观者反应递出。

## 允许与禁止清单

### 允许

1. 名物夹注 `（蒙语‘库里尔泰’是……的意思。）`、`（“哈达”即手帕……）`——蒙语、官制、习俗注释是本书夹注的正确打开方式
2. 回末三层定式（`正是：` 挂正文段尾 + 对句 + `欲知后事如何？请听下回分解。`）
3. 台词内单引号标注专名与成句（`‘瀚海’`、`‘惊鸿照影’`）
4. 歌谣每行独立成段、`"` 开头跨段不闭合
5. 招名加引号（`“毒蛇吐信”的招数`、`“金弓十八打”`）、穴位暗器加引号
6. `说时迟，那时快`、`心念未已`、`话犹未了` 式动作接榫

### 禁止

1. 擅自添加独立写景段与抒情旁白（本书景物段仅 0.3%）
2. 使用原著不存在的华丽辞藻、文艺腔
3. 改变叙事视角、加冗余心理独白块
4. 出现通用AI白开水式平铺直叙
5. 堆砌网络流行梗
6. **一句一段的对话排版**（本书仅 1.3%，除歌谣喝叫外一律不用）
7. **段首破折号**（样本 0 处）
8. 系统流词汇滥用（`系统/任务` 本书虽有但均为普通词义，禁当术语用）
9. 文言腔硬拽（`甚么/知晓/心下/兀自` 本书全为 0 或近 0——本书是八本中最白话的）
10. 章末多余冒号（`：` 段尾只出现在 `正是：` 与引文标签段）
11. 照搬其他梁羽生版本的套语与用字——本书是纯"请听"（20:0）、"看"不是"瞧"、"什么"不是"甚么"
12. 把 `正是：` 写成独占一段（《江湖三女侠》式）——本书 `正是：` 必须挂在正文段尾
