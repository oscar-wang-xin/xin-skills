# 《亵渎》文风锁定

## 萃取文风规范

### 1. 叙事视角

第三人称限知叙事，叙述者全程隐身，零破壁直呼读者（无「各位读者」「要知后事」类套语）。视角锚定主角：罗格（正文出现 314 次，压倒性）、奥菲罗克（103）、风月（47）、奇薇（55）、迦兰（42）。内心活动极少（心中 15 / 心下 1 / 暗自 1 / 却不知 1），角色心理主要靠外部动作、神态、对白外显，不强行钻进多人脑内。非全知，不跳叙群像内心。

### 2. 句式特征

平均段长 89.1 字、中位数 68 字、最长 418；段长分布：51-100 字占 31.6%、101-200 字占 27.2%、21-50 字占 26.1%、≤20 字占 8.1%——**中长段为主，51-200 字段合计 58.8%**。平均句长 29.2 字（以 。！？； 切分）。标点密度：逗号 48.3/千字、句号 28.1、感叹号 3.3、问号 2.2、冒号 1.7、顿号 0.6。段落末字符 TOP：。432 / " 98 / ！23 / ？11。破折号 —— 零出现（版本归一化，勿禁）。整体是「逗号高频串联的中长句 + 稳健分段」，既不是短句炸爽流，也不是猫腻式超长句铺陈。

### 3. 对话体系

对话占比仅 16.6%，纯叙事段高达 94.2%（几乎全为叙事推进，对话嵌入其中）。平均台词 35.7 字、中位数 18 字。含引号段落 36.2%。对话标签极简且固定：**「道：」44 次压倒**，其次「说道：」6、「笑道：」6、「问道：」6、「喝道：」3、「叫道：」1，偶见情绪修饰「冷冷的道」「怒道」。情绪不靠标签词堆砌，而靠前后短动作/神态叙述外显（如「冷哼了一声。凯特走过去，对骑士低声问道……」）。

### 4. 叙事节奏

过渡词平稳：忽然 15、原来 8、登时 3、转瞬 1、片刻 4、跟着 3、一晃 1。冲突以中速推进，常用「忽然／原来」制造转折与信息反转；世界观 exposition 不单独成块，而是揉进叙事与人物行动里（如「魔法师的法力是和他的财富成正比的」随主角身世自然带出）。日常闲笔占比低，主线推进紧凑。

### 5. 词汇与修辞

- **西幻专有名词体系**（自成一格，非系统流）：魔法 257、法师 195、骑士 107、魔法师 75、佣兵 72、圣堂 61、武士 56、魔族 54、贵族 49、风月 47、黄金狮子 39、亡灵法师 39、法阵 30、神之本源、黄金、火焰、魔力、莱茵。
- **现代白话基底**：看 138、已经 83、什么 79、自己 89、没有 56、知道 53、突然 32。
- **修辞**：比喻用「如同」17、「一般」15、「宛如」2、「似的」2；拟声「的一声」13、「嘿嘿」8、「哈哈」4、「呵呵」3。整体修辞克制，不堆排比。
- **轻文言虚词可作点缀**（非硬规则）：何不 6、不该 3、咱们 13、如何 13、罢 10、何况 8、良久 4——但主体是纯现代白话，不可为古风硬拽文言。

### 6. 情绪基调

暗黑、欲望、权谋、反英雄。爽感来自**弱者逆袭、智计破局、力量成长、打破规则**，而非等级碾压（无系统/升级界面）。常带情欲暗示与政治权谋暗线。叙述冷峻克制，善用**冷幽默与反讽**收束（如「就算已经是不折不扣的婊子，这牌坊也还是要立的」）。情绪曲线多为：压抑铺垫 → 爆发/反转 → 反讽或留白收束。

### 7. 章节钩子写法

章末钩子三类交替：**留白秘密**（「一个与奥菲罗克共同拥有的秘密……」）、**对白未竟**（「我终究会胜你一次的！」迦兰痴痴地想着）、**意象隐喻/反讽思辨**（「亡灵法师终于瞒过了天界，在棋盘上放下了那枚苹果」「就算已经是不折不扣的婊子，这牌坊也还是要立的」）。多用省略号留白或感叹号收束，短句收尾，钩子即下章引子，不另作解释。

### 8. 环境描写

疑似纯景物段仅 5/566 = 0.9%，字数占比 2.0%——**环境白描极低**。场景靠动作、对白推进，偶用两三句短句点染（「雪后初睛。莱茵城整个城市披上一片银色。」），不做长篇景物铺陈。地理环境（莱茵城、魔域森林、索伦贫民区）以功能性叙述带出，服务于情节而非审美。

### 9. 行文禁忌

- 系统流/修仙界面词全 0：系统 0、宿主 0、面板 0、升级 0、境界 0、丹田 0、元婴 0、筑基 0、觉醒 0 → **严禁系统流/金手指面板/修仙等级词**。
- 破壁/说书套语全 0：读者 0、要知后事 0、列位看官 0、且听下回 0、内心深处 0 → **严禁直呼读者、章回体套语**。
- 「任务」12 次为西幻正常叙事词（接任务/完成任务），**非系统流界面词，可正常用**；「不由自主」3、「这一刻」3 为弱特征，无碍。
- 古风硬词不当硬规则（见样本说明 A 类陷阱）。

### 10. 开篇习惯

场景直切与长句铺陈混合，无冗长前奏。短句直切型：「烈日，无风，无尽的原始森林和巍巍山脉。」；长句铺陈型：「神圣历682年，罗格·奥塔·里弗斯已经在莱茵魔法学院里呆了四个年头了……」。开局即给世界观/环境/时间锚点，前 200 字信息密度高，常从环境、动作或时间点切入，迅速把读者拉进场景。

## 段落与句式约束

1. 段长以 50-200 字为主（占比近六成），避免超长段落（>400 字极少），也避免碎片化碎段。
2. 句长中等（约 30 字），逗号高频串联成长句流；破折号按标准用法书写（样本零出现是版本缺陷，非作者习惯）。
3. 段落以 。/" /！/？ 收束，少用无终止标点；段末留白可用省略号制造余韵。
4. 杜绝大段密集长段落，杜绝书面化书面腔。

## 对话写作规范

1. 角色台词风格：西幻口语化，带冷幽默与反讽，不端着。
2. 动作神态搭配：极简，标签前偶加一句短动作/神态（「冷哼了一声」「冷冷的道」），不堆形容词。
3. 对话节奏与长度：对话占比低（约 17%），不堆对话；单句台词可长可短，平均 35 字左右。
4. 对话标签使用规则：主用「X道：」「X说道：」「X笑道：」「X问道：」，情绪靠前后叙述外显，不靠「X愤怒地喊道」式标签词。

## 环境描写规范

1. 描写密度上限：纯景物段控制在 1% 以内，点染即可，不独立成段铺陈。
2. 描写手法偏好：两三句短句白描（「雪后初睛。莱茵城整个城市披上一片银色。」），功能性服务于情节。
3. 描写位置规则：章首或场景转换时一句点过，不 interruption 主线节奏。

## 章节钩子规范

1. 末尾悬念类型偏好：留白秘密 / 对白未竟 / 意象隐喻 / 反讽思辨，四类轮换。
2. 末尾句式特征：省略号留白或感叹号收束，短句，钩子即下章引子。
3. 与下章衔接方式：不解释，留白或意象自然过渡到下章开头。

## 开篇规范

1. 开篇切入方式：场景/时间/动作直切，无冗长前奏。
2. 开篇句式偏好：短句直切与长句铺陈混合，首句即可立住场景。
3. 前 200 字信息密度要求：高，迅速给出世界观/环境/人物锚点。

## 叙事节奏规范

1. 冲突切入速度：中速，用「忽然/原来」制造转折与信息反转。
2. 铺垫方式：世界观 exposition 揉进叙事与人物行动，不单独成块。
3. 日常描写占比上限：低，主线推进紧凑。
4. 信息释放节奏：渐进，西幻设定随情节展开，不一次性倾倒。

## 词汇修辞规范

1. 允许使用的高频词汇清单：西幻体系（魔法/法师/骑士/圣堂/魔族/亡灵法师/法阵/神之本源/黄金狮子）+ 现代白话（看/已经/什么/自己/没有/知道/突然）+ 轻文言点缀（何不/不该/咱们/如何/罢/何况）。
2. 惯用修辞手法及示例：比喻用「如同/一般」（「整个世界都仿佛在波光中轻轻摇动」）；拟声「的一声」「嘿嘿」「哈哈」。
3. 规避的词汇类型：系统流界面词（系统/宿主/面板/升级/境界/丹田/元婴/筑基/觉醒）、说书套语（要知后事/列位看官/且听下回）、为古风硬拽的文言词。

## 情绪基调规范

1. 整体调性定位：暗黑、欲望、权谋、反英雄；冷峻克制。
2. 每章情绪曲线模板：压抑铺垫 → 爆发/反转 → 反讽或留白收束。
3. 幽默使用规则：冷幽默与反讽（「婊子立牌坊」式），不滑稽、不卖萌。
4. 爽感来源与触发频率：弱者逆袭、智计破局、力量成长、打破规则；非升级碾压。

## 允许与禁止清单

### 允许
1. 样本中出现的所有叙事手法、节奏、修辞模式。
2. 西幻世界观专有名词体系（魔法/法师/骑士/圣堂/魔族/亡灵法师/法阵等）。
3. 现代白话为基底 + 少量半文半白虚词点缀（何不/不该/咱们/如何/罢/何况）。
4. 低密度对话 + 极简「X道：」标签的嵌入方式。

### 禁止
1. 擅自添加大量无关环境描写、空洞旁白（纯景物段须 <1%）。
2. 使用原著不存在的华丽辞藻、文艺抒情段落。
3. 改变叙事视角，强行增加冗余心理活动或钻进群像脑内。
4. 出现通用 AI 白开水式平铺直叙或书面腔。
5. 随意堆砌网络流行梗、系统流金手指面板、修仙等级词。
6. 破壁直呼读者、章回体说书套语（要知后事/列位看官/且听下回）。
7. 为古风硬拽文言（A 类 ∞ 比值三条已证为陷阱，勿禁白话）。
