# 《我名黄天苍天已死什么鬼》文风范例（玉庭君）

> 以下段落均摘自前20章纯净样本（保留原文「」『』【】与什幺/怎幺拼写），每条标注其示范的文风点。仿写时对照体会节奏、标点密度与玩梗语气。

---

### 例1 · 微信聊天体【】（第9章）—— 现代感 + 玩梗记号

```
咻～
咻～
正吃着时，手机忽然来了几条信息。
黄天点开一看，竟然是女朋友宗文君发来的。
【摸摸猫头.gif】
【方便视频吗，有点想你】
黄天：【方便】
消息发出去的下一秒，手机就震动起来，黄天点击接通。
```

> 示范：用【】框表情包与聊天记录，是本书独特现代感。拟声词「咻～」独占成段作节奏节拍。

---

### 例2 · 主角超能力沙雕吐槽（第2章）—— 现代白话 + 反差幽默

```
世界上所有名为黄天的人，都成为了我的信号基站！
无论谁提起『黄天』这个人，无论其所谈及的『黄天』是不是专指我，我都能看到那人说话时的场景！
```

> 示范：主角用现代互联网/通信梗（"信号基站"）理解超能力，理性吐槽制造笑点。『』用于强调专名。

---

### 例3 · 沙雕金句（第8章）—— 自嘲网感

```
只是黄天却并不因此得意，他知道自己的一切成就都是挂给的。
挂逼发育的快，不是理所当然的吗？
```

> 示范：用网游黑话"挂逼"自嘲，口语反问收句（高叹号/问号密度来源）。

---

### 例4 · 历史人物现代白话对话（第9章）—— 无文言腔的玩梗

```
「大兄，你……何必强撑，守城诸事自有弟代劳。」跪坐一边的张梁眼眶微红，伸手扶住张角。
「如今最紧要的恐怕不是守城了。」张角叹气：「卢植现在已经将广宗团团围住了吧？」
```

> 示范：张角、张梁等历史人物用现代白话对话，无文言腔。对话标签"道/叹气"主导。

---

### 例5 · 黄巾口号玩梗（第9章）—— 历史梗 + 高叹号

```
蓦地，一道熟悉的声音传进他的耳朵里。
「苍天已死，黄天当立，岁在甲子，天下大吉！！」
```

> 示范：真实历史口号被主角穿越触发，双叹号收束强化玩梗爽感。

---

### 例6 · 省略号独立段留白（第2章）—— 情绪/转场

```
只是，有了第一次，是否还有第二次？
```

> 示范：章末以反问+短句留白收束（省略号/短段是本书节奏招牌，常单独成行）。

---

### 例7 · 生活白描接地气（第2章）—— 反差衬托荒诞

```
黄天熟练地点餐扫码，找了个壁挂电风扇能吹到的角落坐下。
没多久，三十多岁的老板端着木桶饭过来。
黄天拿起一次性筷子慢条斯理地吃着，配上他斯文俊秀的外表，看上去就像一个还没走出校园的学生。
```

> 示范：大量当代生活细节（扫码/木桶饭/电风扇/蜜雪柠檬茶）建立真实感，与穿越修仙形成荒诞反差。

---

### 例8 · 多POV群像玩梗（第18章）—— 历史人物拉郎

```
卢植跪坐首位，愁眉不展，他左手边跪坐一人，名为曹操，姿貌短小，目光锐利，右手边跪坐一人，名为董卓，粗壮体肥，须发浓密。
```

> 示范：历史人物以现代白描手法群像出场，为章标题玩梗（"曹操：和一群虫豸共事，怎能匡扶汉室？"）铺垫。

---

### 例9 · 主角被裁的现代感吐槽（第9章）—— 自嘲

```
黄天想了想，觉得没什幺好隐瞒的，「还行，就是被公司当成人才输送给社会了，准备另外找个事做。」
```

> 示范："人才输送给社会"=被裁的网感自嘲。注意用"什幺"非"什么"、"怎幺"特殊拼写（玉庭君前段偏好）。

---

### 例10 · 拟声独立段 + 跨界转场（第9章）

```
噼啪～
水晶破碎的声音传来，那点意识顺利穿过时空屏障，循着声线的方向遁入冥冥的虚空之中。
```

> 示范：拟声词「噼啪～」独占成段，作跨界/动作转场节拍，配合省略号独立段使用。

---

## 仿写节奏总览

1. **短段碎句**：平均32字，84%段落≤50字，敢换行。
2. **拟声/省略号独立段**：咻～ / 噼啪～ / …… 常单独成行作节拍与留白。
3. **高叹号高省略号**：玩梗吐槽外放（叹号8/千字）、欲言又止留白（省略号7.3/千字）。
4. **微信聊天体【】+ 历史人物现代白话玩梗**：现代感与梗文化的两大招牌。
5. **生活白描反差**：用当代细节建立真实感，衬托穿越/修仙荒诞。
6. **疑问词混用**：什幺/什么、么/吗皆可用，禁甚幺/啥/咋；前段可保留"怎幺/要幺"特殊拼写。
