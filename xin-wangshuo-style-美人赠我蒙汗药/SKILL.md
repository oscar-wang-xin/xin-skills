## 二、十维风格规范（详细）

### 1. 体式：双人对谈，没有叙述者
- **只有两个人的话**：`老侠：` 与 `王朔：` 交替；没有「他说」「我问他」「场面如何」。
- **没有情节**：不讲故事，只谈观点、作品、人物、现象。
- **没有景物**：不写天气、房间、街景；所有具体性都来自**例子**（作家、作品、事件）。
- **没有引号对白**：对白就是标签后的整段话；术语和引语才用 `"..."`。
- **一篇一个话题**：标题直接点题（如「写作与伪生活」「金庸的媚俗与媚俗的余秋雨」）。

### 2. 轮次：严格交替，长短有别
- **624 轮，老侠 312、王朔 312**：基本一人一轮，偶尔一人连说两段，但整体交替。
- **老侠更长**：均值 201.6 字、中位 119；喜欢铺开、抽象、下判断、追问。
- **王朔更短**：均值 150.7 字、中位 82；喜欢短 bursts、自嘲、举例、承认、反问。
- **王朔的短轮**：≤50 字有 130 轮（老侠 95 轮）；他常用一句半开玩笑的话接住对方的严肃。
- **平均 1.39 段/轮**：一轮通常一段，有时两三段；**不要一句一段**。

### 3. 句式：长句、逗号推进、书名号多
- 句长 **32.9 字**；逗号 53.3/千字、句号 26.7、问号 2.2、叹号 0.4。
- **长句靠逗号推进**：一个判断后面跟例子、转折、补充；但要有主谓、有落点。
- **书名号 2.7/千字**：大量点名作品（《顽主》《空中小姐》《红楼梦》《废都》《文化苦旅》……）。
- 冒号 5.5/千字：常用于「我告诉你：……」「问题是：……」。
- 问号不多（2.2），但**一问就逼人**：「你什么意思？」「你凭什么这么说？」

### 4. 词汇：文化批评词 ＋ 京味痞话
- **文化批评词**：文化、大众文化、精英文化、学院派、知识分子、传统、文学、电影、媚俗、无耻、诚实、自由、话语权力、意识形态。
- **京味痞话**：点儿、甭、丫的、他妈、操、牛逼、傻逼、腕儿、跌分儿、套磁。
- **人物/作品名**：鲁迅、金庸、余秋雨、王蒙、钱钟书、张承志、贾平凹、张艺谋、崔健、王朔自己。
- **文言几乎为零**：不要「之乎者也」。
- **不要学术黑话堆砌**：可以有「话语权力」「东方主义」，但要马上用大白话解释或嘲讽。

### 5. 声音：老侠与王朔必须分开
- **老侠**：
  - 严肃、学理、逼问、下判断。
  - 喜欢「你的问题在于……」「你这么说就有点儿……」「我不这么看」。
  - 句子更长，逻辑更绕，火气更冷。
- **王朔**：
  - 自嘲、痞、具体、反问、承认。
  - 喜欢「我操」「甭跟我来这套」「你这么说就有点儿不仗义」「我也是这么想的」。
  - 句子更短，例子更具体，姿态更低。
- **两个人会互相拆台**：老侠逼问，王朔躲闪/承认/反将一军；不要写成互相捧。

### 6. 论点推进：追问—反驳—举例—认输/反将
- **不是叙事，是交锋**：每一轮都要接住上一轮，不能各说各的。
- **常见推进**：
  1. 老侠抛判断/追问；
  2. 王朔自嘲/举例/承认；
  3. 老侠不放过，继续逼；
  4. 王朔反将一军或认输。
- **允许跑题**：从文学跑到电影、从电影跑到知识分子、从知识分子跑到性；但跑题要有人接。
- **不总结**：不要「综上所述」「总之」；让最后一轮停在半空。

### 7. 例子：具体到人名、作品、事件
- **点名**：鲁迅、金庸、余秋雨、王蒙、钱钟书、张承志、贾平凹、张艺谋、崔健……
- **点作品**：《顽主》《空中小姐》《红楼梦》《废都》《文化苦旅》《一个人的战争》……
- **点事件**：评奖、港台腔、电影审查、文坛论争、性描写争议。
- **例子要带态度**：不是百科介绍，是「我看不上」「我佩服」「这他妈就是……」。
- **不要空谈**：每个抽象判断后面至少一个具体例子。

### 8. 情绪：愤怒、轻蔑、自嘲、疲惫、较真
- **愤怒**：对虚伪、媚俗、无耻、学院派、主流文化。
- **轻蔑**：对金庸、余秋雨、文化恐龙、伪知识分子。
- **自嘲**：王朔承认自己俗、自己媚俗、自己挣了钱。
- **疲惫**：谈多了、骂累了、觉得没劲。
- **较真**：老侠不放过任何一个逻辑漏洞。
- **不要冷静学术**：这是带火气的对谈，不是论文。

### 9. 篇章：一篇一个话题，标题直接点题
- **篇标题**：写作与伪生活 / 做不了你自己 / 谁的理想与价值 / 自贱与贱人 / 残酷的传媒 / 误读歪曲与人身攻击 / 金庸的媚俗与媚俗的余秋雨 / 谁造就了文化恐龙 / 知识的诚实与道德 / 可怜人必有可恨之处 / 导演能坚持什么 / 要市场或者要艺术 / 生活里有一种野蛮的力量 / 传统也可能是一种骗术 / 无聊的传统继承者 / 从厚黑学里找谋略 / 文学史上谁站得住 / 悲剧的鲁迅 / 文学语言的泛政治化死亡 / 有没有不猥琐的性描写。
- **标题就是论点**：不要文艺标题，不要悬念标题。
- **一篇内可以跳**：但始终围绕一个话题。

### 10. 开篇习惯：直接开问/开骂
- **篇首多是一句判断或追问**：「你的创作，从《顽主》才开始找到自己……」「学术界、学院派的追风一点儿也不次于大众文化。」「中国电影的可笑在哪儿呢？」
- 第一句就进话题，不交代背景、不写场景。
- **不要写天气、不要写「在一次访谈中」**；直接进入对话。
- **篇首不要总结**：把判断抛出来，让对方接。

## 三、仿写执行规则（硬约束）

### 体式
1. 只用 `老侠：` 和 `王朔：` 两个标签；**不要加叙述、不要加场景、不要加「他笑着说」**。
2. 严格交替；一人一轮；偶尔可以一人连说两段，但不超过两段。
3. 每轮 1–3 段；一段 50–300 字；长轮可以到 600–800 字。
4. **不要一句一段**；这是对谈，不是网文。
5. 篇与篇之间用 `## 第N篇 标题` 分隔。

### 句子与标点
1. 句长 28–36 字；逗号密度 50–56/千字；句号 25–28。
2. 问号 2–3/千字；叹号 ≤0.5；冒号 5–6。
3. 书名号 2–3/千字：多点名作品。
4. 术语/引语用 `"..."`；书名用《》；**对白不用引号**。
5. 段末必须落 `。`／`？`／`！`，不许以逗号悬空。

### 声音
1. 老侠：长句、判断、逼问、冷火；多用「你的问题在于」「你这么说就」「我不这么看」。
2. 王朔：短句、自嘲、举例、承认、反将；多用「我操」「甭」「你这么说就有点儿不仗义」「我也是这么想的」。
3. 两个人要**互相拆台**，不要互相捧。
4. 王朔可以认输，但认输里要带刺。
5. 老侠可以下判断，但判断后面要举例。

### 内容
1. 每篇一个话题；标题直接点题。
2. 每个抽象判断后面至少一个具体例子（人名/作品/事件）。
3. 允许跑题，但跑题要有人接。
4. 不要百科式介绍；要带态度。
5. 不要总结、不要「综上所述」。

## 四、允许与禁止清单

### 允许
1. 京味痞话、脏话、自嘲、骂人。
2. 文化批评词：大众文化、学院派、知识分子、媚俗、无耻、诚实、自由。
3. 点名作家/作品/导演/事件。
4. 长轮次、长句、长段。
5. 互相拆台、逼问、认输、反将。
6. 跑题、跳话题、临时改口。
7. 愤怒、轻蔑、疲惫、较真。
8. 篇末停在半空，不总结。

### 禁止
1. 叙述、场景、景物、情节。
2. 一句一段、网文节奏。
3. 学术论文腔、四平八稳。
4. 两个人互相捧、各说各的。
5. 只谈抽象、不举例。
6. 2020 年代网络梗、文言腔。
7. 篇末总结、升华、点题。
8. 把王朔写成圣人、把老侠写成反派。

## 五、写作执行要求

1. **先定一篇一个话题**：写作、电影、知识分子、传统、性、道德。
2. **第一句就抛判断/追问**，不交代背景。
3. **老侠先开炮，王朔接**；或王朔先自嘲，老侠逼。
4. **每轮 1–3 段**，老侠长、王朔短。
5. **每个判断后面至少一个例子**：人名、作品、事件。
6. **每篇至少一次互相拆台、一次认输/反将、一次脏话/自嘲**。
7. **术语用 `"..."`，书名用《》**，对白不用引号。
8. **篇末停在半空**：一句判断、一句反问、一句自嘲；不总结、不升华。
