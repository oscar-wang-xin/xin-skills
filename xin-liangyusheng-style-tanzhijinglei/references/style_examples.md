## 一、卷首词与回目

卷首用纳兰容若《沁园春》全词开卷，署名单独成段，是全书唯一一处段首 `——`：

```text
试望阴山，飘风销魂，无言徘徊。见青峰几簇，去天才尺，黄沙一片，匝地无埃。碎叶城荒，拂云堆远，雕外寒烟惨不开。踟蹰久，忽冰崖转石，万壑惊雷。
穷边自足愁怀，又何必平生多恨哉？只凄凉绝塞，蛾眉遗冢；销沉腐草，骏骨空台。北转河流，南横斗柄，略点微霜鬓早衰，君不信，向西风回首，百事店衰。
——纳兰容若·沁园春
```

**分析**：末句"百事店衰"是录入错字（印刷版作"百事堪哀"）。引词启卷后**不解释、不评论**，第二段直接落到昆仑山的地理描写，中间不设过渡句。

回目一律**七言对仗两句**，与回末的"正是"诗形成首尾呼应：

```text
第1回 远涉穷边逢侠女 横穿瀚海觅孤儿
第2回 冰窟藏身求秘笈 魔城现影说前因
第20回 欲道心魔求棒喝 难挥慧剑令钮分
```

## 二、开篇六型

### 型一：引诗词 + 议论（第 1、3 回）

```text
“天苍苍，野茫茫，风吹草低见牛羊。”这是描写寒外风光，传诵千古的名诗。
塞外风光，不但能令英雄倍增壮志，而且它像是一个有神奇医术的大夫，不管你心底有多少愁烦，在大草原的怀抱之中，都能令你心胸开阔，愁郁顿消。
```

**分析**：先引名句，紧接着一句**议论**把风景转成对人的作用（"像一个有神奇医术的大夫"），第三段才落到具体地点与人物。这是梁羽生独有的"起兴 + 讲道理"开场，**全书 20 回只用 3 回，不可回回照搬**。

### 型二：对话直切（第 4、5、7、9、10、14、17、20 回，最多的一型）

```text
杨大姑面色一沉，说道：“你忘记了咱们的家训吗？”齐世杰道：“孩儿没有忘记。”杨大姑道：“念出来给我听听。”
```

**分析**：开篇第一句就是台词，无任何前情介绍。**一段内三人称代答**（母子来回），是本书对话排版的常态。

### 型三：动作先落地（第 8、13 回）

```text
缠斗中两把剑再次搭在一起。
```

### 型四：场景 + 人物定位（第 6、12、15、19 回）

```text
此际杨炎正在鲁特安旗的草原上踽踽独行。
冷冰儿在想念着他，他也在想念着冷冰儿。
```

**分析**：第 6 回开篇连用三段极短句，一段一件事，情绪先于事实，随后才展开叙述。

### 型五：承接上回动作（第 2、16 回）

```text
释湛陷落冰窟窿，惨叫之声从层冰底下隐隐传出，更是令人听得毛骨悚然，齐世杰的修为尚未能做到“视而不见，听而不闻”的地步，听得这惨叫之声，不觉心头一震。
```

### 型六：跨回顶针（第 17→18 回，全书仅此一次）

```text
只在此山中，云深不知处。杨炎只好信步所之，走入深山密林，碰碰自己的运气了。
```

**分析**：上一回末的"正是"诗，直接成了下一回的首句。这种黏连全书只用一次，用多了会显得取巧。

## 三、句式与段落

### 饱满段的典型形态：一段内织"叙述 + 台词 + 动作 + 判断"

```text
她正想问罗曼娜听见没有，罗曼娜已在说道：“咦，好像是有人爬山。”
冷冰儿居高临下，凝眸俯瞰，隐隐约约在草原上发现几个黑点，黑点渐渐并大，看得出是人的轮廓了。知道罗曼娜说得不错，不禁暗自好笑：“我只从敌人方面着想，却没想到是自己人的来援救我们。”当下，吸一口气，把声音送出，高声问道：“谁在下面？”口中说话，脚步不停，牵着罗曼娜加速奔下。
```

**分析**：第二段 130 余字，含"动作—观察—心理—开口—动作"五个层次，**这是本书的标准推进单位**。写梁羽生，一段就要这样写满，不能拆成五行网文短段。

```text
那风声果然甚为古怪，似是诸声杂作，或如战鼓雷鸣，或如空山梵唱，或如巫峡猿啼，或如高岗虎啸，或如鹤唤九弄，或如鲛人夜泣……雄壮、凄沧、哀号、温婉，各种奇怪腔调，兼而有之，构成了极不和谐的合奏。少年人也止不住魄动神摇。
```

**分析**：六个"或如"排比 + 四词总括（雄壮、凄沧、哀号、温婉）+ 落在人的反应上。**排比是本书描写的主力手法**，但一定收在"人"身上，不收在景上。

### 悬念短段：每回三五处的换气口

```text
那知他一拔剑出鞘，却得到意想不到的结果！
她料得不错，但可惜也只是猜中了一半。
突然他感到一阵晕眩。
```

**分析**：这三句都独立成段，前后都是四五十字的长段。**短段在本书里是"标点"而不是"节奏"**——用在转折点上敲一下，敲完立刻回到饱满叙述。全书 ≤20 字的段只占 16.4%。

### 写景挂人：景不独立成段

```text
走出幽暗的峡谷，满眼又是灿烂的阳光。
可是杨炎的心头，却还是布满阴云。
```

**分析**：两句一段一景一情，光是"反衬"。全书疑似纯景物段只有 23 / 7,651 = 0.3%，**没有一段纯粹的风景描写**。

## 四、对话体系

### 标签双轨：`说道` 与 `道` 并用

```text
那少女淡淡说道：“我是在当你遇难之时，恰巧路过的女子。患难相助，理所当然，何况同是汉人呢，你用不着客气。”齐世杰本是问她姓名的，听她这样回答，自是不能满意。但想她或许是出于施恩不望报的意思，萍水相逢，一时间倒是不好意思立即又再追问他的姓名了。
```

**分析**：一句台词 40 余字（全书台词中位 20 字），后面接 70 字叙述解释"为什么不追问"。**台词说完必有交代**——这是梁羽生的"讲清楚"本能，也是与温瑞安"台词打完就切镜头"最大的区别。

### 段内多人来回

```text
年纪大的那个汉子哼了一声，说道：“咱们的师姑号称辣手观音，你倒怜悯起她来了！辣手观音，平生从不受人怜悯，要是给她知道你说过这样的话，恐怕她非但不领你的情，还要赏你老大的耳括子呢！”
```

**分析**：句末"耳括子"是录入错字（应为"耳刮子"），引文保留原貌。说话人标签前挂 `哼了一声`，是本书最高频的神态钩子（44 次）。

### 机锋藏在人物嘴里

```text
杨炎吃惊过后，笑道：“不是十条小命，是十八条小命！”龙灵珠莫名其妙，说道：“十八条小命，这是什么意思？”杨炎说道：“你数一数，软鞭是不是断了十八段？”
龙灵珠仔细数一数地上作寸寸断的软鞭，果然是十八段。不觉吓得伸出舌头，说道：“好厉害的胡茄十八拍，要是戳在我的身上，果然是十八条小命都完了。”
```

**分析**：这是一场劫后余生的打趣——**绷紧之后立刻用人物机锋放松**，是本书调节情绪的标准做法。注意"胡茄"是错字（应为"胡笳"）。

### 狠话用短句砸出来

```text
龙灵珠咬咬嘴唇，嘴唇在流血，心里也在流血，但却是狠狠的说道：“不错，你帮过我的忙，也帮过别人打过，恩怨早已一笔勾消。从今之后，你当作从来没有见过我这个人好了。恕我不识擡举，我走啦！”
```

**分析**：动作（咬咬嘴唇）+ 身体细节（嘴唇在流血）+ 心理对举（心里也在流血）+ "狠狠的说道"。**情绪最烈的台词，也只到 60 字，靠动词和身体细节撑，不靠排比抒情。**

## 五、叙事节奏与"原来"补叙

"原来"全书 379 次（18.9 次/回），是本书头号叙事机关，专用于**身份揭底、武学溯源、地理掌故**三类倒装补叙：

```text
原来这个少年姓齐名叫世杰，来头可是委实不小，他的母亲是保定名武师杨牧的姐姐，人称“辣手观音”杨大姑。江湖上有两个“观音”，另一个关东大侠尉迟炯的妻子“千手观音”祈圣因。两个观音，“辣手”“千手”，相差一字，各擅胜场，杨大姑能与祈圣因并驾齐名，本领可想而知。据说杨家的家传绝学六阳手，杨大姑可要比她的弟弟厉害得多。
他的爷爷是北五省顶尖儿的武林高手，慷慨豪侠，天下知名，人称“四海游龙”齐建业。
齐世杰父亲早逝，由爷爷和母亲传授他的武功，他身兼齐、杨两家之长，故此虽然不过二十多岁，在江湖上已经闯出不小名头。这次他跨过昆仑，来到西藏，倒并非是为了猎奇探险，而是为了要找寻一个人。
```

**分析**：**人物登场必带家世交代**——母亲（含绰号与本事的比较）、爷爷（含绰号）、父亲早逝、武功来源、江湖地位，最后一句才落到"此行的目的"。这一整套是梁羽生的人物名片，缺一项就不像。

```text
他发现四面墙壁也有蜂巢般的小孔，小孔有水珠渗出，触水冰冷，舐舐手指，却有咸味，原来是西藏特有的一种岩浆建造的。这种岩浆比普通的石头还要坚硬得多，不过却是最忌雨水渗透，用来建造房屋，墙壁会渐渐由厚变薄，最多不过能维持三五十年。
```

**分析**："原来"在这里引出的是**地质说明**。作者是真的在讲知识，不是抒情——**"讲古"是本书的乐趣来源，不是拖沓**。

```text
原来杨家六阳手脱胎于少林寺的大力金刚掌，少林寺的武学是达摩祖师所传，故而“六阳手”也可算是达摩武学的一个旁支。这个番僧是密宗高手，武学源流出于天竺的那烂陀寺，与达摩祖师当年携来中土的武学正是同源。
```

**分析**：打斗中插入武学源流考，把一场比斗接进"中土—天竺"的武学谱系里。**招式背后必有来历**，这是本书武打的写法。

## 六、武打破解：先给结果，再补招法

```text
但他想不到孟华的剑法竟然精妙如斯，此招一出，电光石火之间，就刺着了他的十八处穴道。力度用得恰到好处，血丝也没渗出半点。但十八处穴道被封，还怎能运功自断经脉。
```

**分析**：先写结果（十八处穴道被封）+ 精度细节（血丝也没渗出半点）+ 人物处境（想自尽而不得）。**招式名后置交代**（后文才补"原来孟华使的最后一招，名为'胡笳十八拍'"）。仿写不要写成"一拳轰出、轰然巨响"式的音效轰炸。

## 七、情绪与韵文

### 悲愤写实，不嚎哭

```text
泪流干了，杨炎的心里充满恨！可是不管杨牧如何可恨，他总是自己生身之父。“我怎么办？我该怎么办呢？”
```

**分析**：句式是"泪流干了 + 心里充满恨 + 可是…… + 自问"。用生理细节（泪干了）落情绪，自问句收尾。

### 情感高点交给民歌

哈萨克民歌出现两次（杨炎一次、冷冰儿一次），是全书的抒情母题：

```text
“圣峰的冰川像天河倒挂，
你听那流冰浮动轻轻的响——
像是姑娘的巧手弹起了东不拉。
她在问那流浪的旅人：
你还要攀过几座冰山？经历几许风沙？
晰啦——一
流浪的旅人呀，
草原的兀鹰也不能终日盘旋不下，
你们尽是走呀，走呀，走呀！——
要走到那年那月，才肯停下你们的马？”
杨炎并不是第一次听见这首民歌，但却从没像这次的深受感动。
因为他觉得自己像是在人生的旅途，摸索前行的道路，而在以前，更确切的说，在他未曾知道自己身世之隐以前，他是没有这种感觉的。他不知不觉哼起这首民歌的后半段，这后半段是“旅人”的回答，好客的哈萨克人是只唱前半段的。
“姑娘呀，多谢你的好心意，
只是我没办法回答。
你可曾见过荒漠开花？
你可曾见过冰川融化？
你没有见过？没有见过呀！
那么流浪的旅人哪，他也永不会停下！”
可是在他哼完这后半段歌词的时候，他的脚步却不知不觉地停下来了！
```

**分析**：**歌是分行的，每行独立成段**（这是全书唯一"一句一段"被允许的地方）。歌后必有作者接话解释"为什么唱"——用歌词反打人物处境（唱完"永不会停下"，脚步却停下了）。

### 女儿心事用口占一诗

```text
“身向南边望北云，风云变幻几浮沉，芳心破碎倍思君！”
```

**分析**：三句七言，不标出处，直接插在冷冰儿的心理段后。**抒情高点用韵文收，不用大白话嚎**。

三例带上下文（看"悬念句 + 正是 + 诗"的三段式）：

```text
齐世杰见四周静悄悄的，心想：“娘大概不会起得这么早，待我换了一套衣服，再去见她，免她吃惊。”
那知他一踏进卧房，只见母亲已是坐在他的房中了。正是：
风波平地起，母子最关心。
```

```text
杨炎的流血已经止了，但衣裳上还是血迹斑斑。
正是：
不道师门难见谅，竟教兄弟动干戈。
```

```text
他和龙灵珠都还未满二十岁，倘若按照佛门说法，百岁光阴也不过一弹指的话，他们这点小小的年纪，实在是经历太多的忧患与风波了。一弹指间曾有多少闪电惊雷！正是：
惘惘情怀难自解，于无声处听沉雷。
```

**分析**：诗必须**扣住本回事实**——第 12 回诗说的是齐世杰讨五万两（"语出惊人岂为财"），第 13 回说的是母子对峙（"风波平地起，母子最关心"），第 16 回说的是少爷吸毒（"甘为瘾君子，少爷变奴才"）。**写空泛的抒情句就废了**。注意第 10 回形态略异：`正是：` 单独成段（其余 19 回粘在叙述段末）。

## 九、神态动作钩子库（可直接调用）

| 钩子 | 全书次数 | 用法 |
|---|---|---|
