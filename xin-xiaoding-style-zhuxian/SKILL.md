# 文风锁定 Skill：诛仙（新修版）· 萧鼎

> 本 Skill 用于指导 AI 按萧鼎《诛仙》（新修版）前20章（第1章《青云》至第20章《魔踪》，约10万字）的文风进行小说创作。所有风格结论均基于样本实测 + 全本（约110万字）对照，禁止凭空脑补。

## 样本说明

- **来源**：《诛仙（新修版）》txt，GBK 编码，约109.9万字；提取前20章清洗后约10.0万字。

- **全文校验结论**：以下所有标点比例、用词比值均已对全本做 `str.count()` 对照，样本与全本比值一致，确认是**作者风格而非版本缺陷**：

- **版本瑕疵说明**：样本引号 1166/1165 差1，系中文"跨段落续引"标准用法（前段末不闭引号、后段开头另起开引号）所致，非缺陷；范例摘录不受影响。

## 维度1：叙事视角

- **人称与限知**：第三人称限知，死锁主角**张小凡**（样本最高频词，722次）。叙述基本不离开主角感知范围，重大转折（草庙村惨案、入青云）均经主角眼睛带入。
- **内心活动**：用"心中"明标（5.5次/章，110次），"心道/心想"较少（4/7次）；情绪多用"心中一紧/大是着急/暗自"等短语，绝不转"我"。
- **观察入角**：古典白描视角词高频——"只见"4.0次/章（81次）、"只听"1.1、"忽听"0.7、"但见"0.8。用于切换场景或引出异象，是传统白话小说习惯。
- **全知尺度**：极少跳出主角做上帝视角评点；门派渊源、功法体系等多借配角之口叙述（如宋大仁讲道），保持限知。

## 维度2：句式特征

- **段长句长**：平均段长 **61.0字**（中位数55），平均句长 **41.2字**（以。！？；切分）。典型"逗号连缀长句"（逗号74.7/千字），一句常由3-5个分句逗号串起，末以句号收束。
- **标点节奏**：
  - 冒号 7.5/千字（高，叙述说明、引语提示多）；
  - 问号 2.66/千字、感叹号 1.88/千字、省略号 1.92/千字（全本一致，活跃且完整，**非版本归一化**）；
  - **破折号极慎用**（全书0.05/千字，样本11次，多在"修真门派——'青云门'"这类解释性插入）；
  - 顿号 1.22/千字、分号 0.12/千字（古典克制，莫滥用）；
  - 单引号 0.28/千字，**仅用于双引号内嵌套**（如'万蝠古窟'），不单独使用。
- **长短句配合**：叙述铺陈用长句，对话与战斗高潮用短句爆发（"好剑！""你竟是青云门下！"）。

## 维度3：对话体系

- **占比与长度**：对话占比 **22.8%**，平均台词 **19.7字**（中位10字，偏短）。纯对话独立成段仅 **4.0%**，多数台词**嵌在叙事段内**（"张小凡大声道：'……'"），不像都市网文那样大量独立对话段。
- **说话标签**：朴素，**"道"压倒性**（683次），辅以"笑道"85、"怒道"11、"问道"23、"奇道"6、"叫道"7；**几乎不用"说道"**（仅3次）。禁用花哨标签（"娇嗔道""冷哼道"类）。
- **口吻**：台词短、信息直给，主角多用急切短问（"王二叔，是你吗？""你说啊！"）；配角讲道/解说时台词变长、信息密度高（宋大仁讲太极玄清道）。

## 维度4：叙事节奏

- **古典过渡词密集**：忽然79（4/章）、忽地27、登时18、随即34、当下26、片刻47、跟着13、原来14、这日/这一日7。这些词构成"传统白话小说"的节奏骨架，仿写时需保留。
- **铺垫厚重**：第1章整章铺垫青云山地理与门派千年史（无主角登场），是典型的"先立世界、后入人物"的仙侠开篇法。日常描写与修炼体感并重（砍竹功课、御剑修行）。
- **时间跨度大**：门派史以"百年/千年"计，主线以"这一日/数年"推进，不以小时级细碎时间流。

## 维度5：词汇与修辞

### 5.1 语体总判定：半文半白（新修版现代化）

**核心词汇全面现代白话**（B类现代体压倒，全本对照确认）：

| 现代体（用） | 古体（不用） | 全本计数 |
|---|---|---|
| 什么 | 甚么 | 1828 : 0 |
| 看 | 瞧 | 6410 : 4 |
| 知道 | 知晓 | 863 : 27 |
| 我们 | 咱们 | 854 : 29 |
| 别 | 勿/休得 | 320 : 1/0 |
| 突然 | 陡然 | 960 : 54 |
| 这么 | 恁地/怎地 | 283 : 1/0 |
| 吗（疑问语气词） | 么（独立语气词） | 577 : 0（孤立"么"） |

> 注：全书"么"2991次绝大多数是"什么/怎么/这么"的组成部分，独立疑问语气词"么"为0。仿写疑问语气统一用"吗"。

**硬规则（A类古体压倒，强证据，写进规范）**：
- **只用"随即"，禁用"马上"**（全本640:22）。
- **只用"说话"，禁用"讲话"**（全本362:2）。

> "良久:很久""甚是:非常"仅1次样本证据，不作硬规则，按中性处理即可。

**中性自由项（C类，可自由混用——这是半文半白的韵味来源，务必保留混合感，不可统一成纯现代）**：
- 如何(289) ↔ 怎么(77)：混用，古雅处用"如何"。
- 如此(526) ↔ 这样(16)：偏"如此"，保留。
- 登时(137) ↔ 立刻(29)：混用。
- 兀自(45) ↔ 仍然(6)：偏"兀自"（"兀自传来'鬼、鬼……'"）。
- 纵然(54) ↔ 即使(1)：偏"纵然"。
- 罢(172) ↔ 吧(99)：两者皆用，语气词多用"吧"，实词（说罢/也罢/罢了）用"罢"。
- 岂(80) ↔ 难道(4)：混用，"岂"增文气。
- 端的(16) ↔ 究竟(4)、当下(171) ↔ 这时(43)、不由得(17) ↔ 忍不住(36)：均混用。

### 5.2 修辞

- **比喻**：用"……一般"公式化比喻（52次，"如死灰一般""如潮水一般"），辅以"便如"5、"犹如"3、"宛若/宛如/好似"各1。比喻朴素、不堆砌。
- **拟声**："的一声"25次（"大叫一声""冷笑一声"）；笑声叠词哈哈/嘻嘻/嘿嘿/呵呵各7-10次，用于轻快场景。
- **专属名词体系**：青云门/七脉/大竹峰/通天峰、太极玄清道/玉清境/神剑御雷真诀/诛仙古剑、真元/法宝/道法/御剑——修真仙侠术语高频且自洽（法宝44、道法20、修习40、玉清境18、御剑9），仿写须保持该术语体系。

## 维度6：情绪基调

- **主调**：古典仙侠的苍凉底色 + 少年成长的温情 + 正邪对峙的肃杀。草庙村惨案后的悲悯、大竹峰师徒的烟火气（惧内师娘、大黄狗）交织。
- **幽默**：轻喜剧点缀（师娘苏茹威慑远超矮胖师父、田灵儿撇嘴），不喧宾夺主。
- **爽感来源**：平凡少年（张小凡资质平庸）逆袭 + 法宝法术奇观（神剑御雷、御空而行），非打脸爽文腔。

## 维度7：章节钩子写法

- **类型**：余韵型（意境画面定格）+ 悬念型（反差/命运转折）混合，少强断崖。
- **余韵型**：第1章末老和尚"碧玉念珠中夹杂一颗深紫暗淡圆珠"的异样定格；第6章末"远处峰前屋宇传来一声长长犬吠，夹杂几声可怜人尖声痛呼"的画面收束。
- **悬念/反差型**：第2章末"神剑御雷真诀！……你竟是青云门下！"的爆发反差；第3章末"张小凡正要抬头看他，却突觉后背被人一拍，登时眼前一黑，又再度不省人事"的命运急转。
- **句式**：章末多用场景定格或短句爆发收尾，句末以。/"收束，留白给读者。

## 维度8：环境描写

- **密度**：纯景物段 2.7%、字数占比 4.8%（中等偏低，不铺陈）；景物多**融入叙事/氛围**而非独立白描段。
- **手法**：开篇远景白描厚重（第1章青云山"巍峨高耸，虎踞中原……峰峦起伏，高耸入云，云雾浓重环绕山腰"）；景物服务于情绪（肃杀/幽美/苍凉），如战斗前"天际乌云翻涌，雷声隆隆，天地间一片肃杀"。
- **位置**：开篇定调、转折处烘托、章末余韵，少用中段大段写景。

## 维度9：行文禁忌

- **绝对禁止系统流**：系统/宿主/任务/面板/升级/金手指/属性点 全0，本书无此设定，仿写不得混入。
- **禁止现代都市口语**：MM/帅哥/牛逼/吐槽 类网文口语（本书0）。
- **禁止硬拽纯文言**：新修版核心词已现代化，用"什么/知道/我们/吗/别/突然/这么"，不写"甚么/知晓/咱们/陡然/恁地"。古雅只限于C类中性自由项的点缀，不可整段文言。
- **禁止网文戏剧化套话**："命运的齿轮""仿佛整个世界""就在此刻""地老天荒""风云变幻"全书0，禁用。
- **禁止滥用标点**：破折号、顿号、分号极克制（见维度2），勿模仿现代网文的破折号连发、顿号罗列。
- **禁止华丽堆砌抒情**：内心活动用"心中一紧/大是着急"等短促短语，勿用"内心深处泛起……的感悟"式升华腔（"内心深处"全书仅5次且为自然用法，非套路）。

## 维度10：开篇习惯

- **切入方式**：三选一——①远景白描（青云山地理定调）；②时间/场景定格（"清晨，这一场雨终于停了"）；③日常切入（草庙村孩童视角）。
- **前奏**：偏铺垫型，允许1章世界建立（门派史、功法体系）再入人物；不追求三行内强钩子。
- **代入**：从环境或配角引入后，迅速落到主角感知（"在张小凡眼中，天上的云……"），保持限知。

## 词汇修辞规范（速查）

**硬规则（必遵）**：只用"随即"不用"马上"；只用"说话"不用"讲话"。
**现代主体（必遵）**：什么/看/知道/我们/别/突然/这么/吗。
**自由混用（保留韵味）**：如何/怎么、如此/这样、登时/立刻、兀自/仍然、纵然/即使、罢/吧、岂/难道、端的/究竟、当下/这时、不由得/忍不住。
**修真术语体系（必用）**：青云门、七脉、太极玄清道、玉清境、神剑御雷真诀、诛仙古剑、真元、法宝、道法、御剑。

## 写作执行要求

1. 第三人称限知，死锁主角；内心用"心中"明标，不转"我"；用"只见/但见/只听/忽听"做观察入角。
2. 句式以逗号连缀长句为主，末以。/"收束；对话与战斗高潮切短句爆发。破折号/顿号/分号极克制。
3. 对话占比约两成，台词短、嵌叙事段；标签统一用"道/笑道/怒道/问道"，禁用"说道"及花哨标签。
4. 保留古典过渡词（忽然/登时/随即/当下/片刻/原来）作节奏骨架；铺垫厚重，开篇可先立世界。
5. 语体半文半白：现代核心词主体 + 古雅虚词（兀自/纵然/如何/如此/罢/岂/端的）点缀，不统一成纯现代、不硬拽纯文言。
6. 比喻用"……一般"朴素公式；战斗写"吟咒（独立段引号）+ 天地异象烘托 + 短句爆发收束"。
7. 章末用余韵画面定格或悬念反差收尾，留白。
8. 严格规避维度9禁忌清单。
