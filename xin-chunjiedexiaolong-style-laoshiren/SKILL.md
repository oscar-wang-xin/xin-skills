# 文风锁定技能：《捞尸人》（纯洁滴小龙）

> 本包基于《捞尸人》前 20 章（约 19.8 万字）清洗样本 + 全本 561 万字对照量化生成。所有硬规则均有全本计数背书，非采样噪声。仿写时严格照"硬规则"与"十维指纹"执行，勿凭感觉。

## 一、作者与作品基底

- **作者**：纯洁滴小龙（节日的小龙 / 纯洁滴小龙，起点都市传奇/年代文代表）
- **题材**：东北乡村**年代传奇**——以崔桂英、李维汉一家为核，串起水运、家族、村俗、死人（捞尸）等市井狠人叙事；现实向，**零修仙、零系统流、零灵异设定**（"捞尸人"是职业不是超能力）。
- **语域底色**：纯现代白话骨架 + **东北方言角色语域**（角色台词带"整/瞅/咋/啥/甭/伢儿"，旁白用标准白话）。态判定 = 纯现代白话（态1），方言是角色腔不是作者叙述腔。
- **非古风书**：B类现代体压倒（看1125:瞧51、知道175:知晓0、已经150:已然0、没有140:未曾0），别为凹古风硬塞文言。

## 三、硬规则（仿写必须执行）

1. **疑问代词统一"幺"拼写**：只用「什幺 / 怎幺 / 为什幺」，禁用「什么 / 怎么 / 为什么」。全本比值 ∞（什幺6011:什么0）。这是本书身份证级硬规则。
2. **单字语气词"吗"几乎不用**（全本仅92次/561万字），可用口语"嘛"做尾音（如"慌急个什幺嘛"），但别硬塞标准"吗"。
3. **对话用纯直角引号「」**，不用全角" "。全本「」54539 vs 全角" "1615（" "是前20章外的极少量，主体系是「」）。『』做书名/特殊称谓，【】偶用。
4. **零内心独白**：不写"心想/心中/心道/暗自"，所有心理全靠动作、对话、神态外化。这是和"没钱修什么仙"最显眼的区别。
5. **零修仙、零系统流、零灵异**：本书是现实年代文，别写丹田/法力/境界/系统/面板。
6. **东北方言仅限角色台词**：整（搞/弄）、瞅（看）、咋（怎么）、啥（什么）、甭（别）、伢儿（小孩）、浪蹄子（贬称）等给村人/家属用；旁白与叙述用标准白话。
7. **"说话"优于"讲话"**：说话634:讲话24（26:1），用"说话"不用"讲话"。

## 四、词汇修辞规范

- **只用**：什幺/怎幺/为什幺、说话、整/瞅/咋/啥（角色）、这幺/那幺（全本这幺/那幺均现代拼写，无需改）。
- **禁用**：什么/怎么/为什么、讲话、吗（硬塞）、丹田/法力/筑基/系统/面板/觉醒/金手指。
- **中性可混**：便/就（便1094:就28038，用"就"为主）、咱们/我们（用"我们"为主）、若是/如果（用"如果"为主）、何况/况且（何况72:况且49近均，皆可）。
- **比喻俗白化**：用生活喻体（"肚皮跟无底洞似的""贼能吃"），忌文艺华丽修辞。

## 五、句式与节奏

- 段长控制在 20–50 字为主，逗号密铺，一句一意，不写长难句。
- 不靠"忽然/猛地/陡然"炸节奏，平实推进；时间跳用"可等暑假一到""婚前寄来的钱"类白描连接。
- 对话独立成段占比高（25.4%），短台词（平均17.5字）穿插叙事。

## 六、对话体系

- 标签"道"绝对主导（354次），辅以"说道/笑道/问道/喊道/骂道/呵斥"。
- 角色台词带东北方言与市井粗粝感（"去去去！""抽什幺疯""没啥事儿啊"），但不脏话连篇，分寸在"狠劲儿"不在"脏"。
- 多角色群像对话（一家子/村里人），用称呼（崔桂英/李维汉/雷侯/英侯）区分，不用"甲说乙说"。

## 七、标点规范

- 对话「」配对；省略号……可用但全本偏低（0.40/千），别密铺。
- 破折号——少用（0.33/千），顿号、少用（0.59/千）。
- 问号/叹号密度低（2.68/1.42每千），情绪克制外放少。

## 八、视角与叙事

- **纯第三人称，零内心独白**：所有人物心理通过动作、神态、对话外化（如"崔桂英没好气地呵斥""李维汉指着鼻子骂了回去"）。
- 叙述者贴地，不介入评价，靠细节（用缸盛饭、推回彩礼钱）立人。

## 九、题材特征

- 东北乡村/水运/家族年代传奇；职业"捞尸"是现实行当（捞溺水死人），非灵异。
- 人物群像：长辈（崔桂英/李维汉）、子侄（雷侯/英侯/潘侯）、村人（郑大筒/刘瞎子），关系靠日常互动立。
- 时间感：暑假、农忙、婚娶、寄钱——年代生活流。
