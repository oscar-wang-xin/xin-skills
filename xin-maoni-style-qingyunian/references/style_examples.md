# 庆余年（第一卷·在澹州）· 文风范例摘录

> 以下段落摘自样本前20章，呈现猫腻"纯现代白话 + 穿越者双重视角 + 重心理轻景物 + 黑色幽默反差"的语感。引文保留原书标点。

## 1. 穿越者破题开篇：用现代电影解构古代（第一章）

小男生长的很漂亮，眉毛如画，双眼清亮无比，声音却还是奶气未褪，但说话的语气却是老气横秋的厉害。

只听他叹了口气，小小的胳膊比划道："话说那楚门走到墙边，发现那里有个梯子，所以一步一步地走了上去，找到了门，所以推门而出……"

"然后呢？"

"然后？然后……自然就是回到人世间咯。"小男生嘟着嘴，似乎很不耐烦旁边比自己大的少年们居然会问出这样弱智的问题。

> 要点：主角范闲以现代人记忆（电影《楚门的世界》）给古代小孩讲故事；"老气横秋""弱智的问题"是现代口语；穿越者滤镜从第一章就立住。

## 2. 穿越者内心OS：现代认知 vs 异世界（第一章）

似乎他想以此来提醒自己些什么，提醒自己是不属于这个世界的人，自己的那个世界里有电影有网络，有YY小说。

……

楚门最后发现了他身处世界的虚假，所以毅然地坐船而行，找到了出口。

但范慎，不，应该是范闲……知道自己不是楚门，这个世界确实是真实存在的，并不是一个大的摄影棚。

> 要点：第三人称心理流（不用"心中"），用"范闲知道自己…"；现代词（电影/网络/YY小说/摄影棚）自然嵌入；"范慎，不，应该是范闲"的姓名切换是穿越者身份标记。

## 3. 冷静吐槽式对话（第六章）

但此时他的卧室里还有一个昏迷不醒的刺客，所以根本来不及问什么，直接开口说道："有人来杀我，现在被我敲昏了，正躺在地上。"

瞎子少年微微侧头，心里微微一动，面上没有一丝表情，低头行了一礼："范少爷在胡说什么？"

> 要点：面对刺杀的淡定吐槽；标签"开口说道/行了一礼"朴素；"有人来杀我，现在被我敲昏了"用短平快口语制造反差喜感。

## 4. 现代实证精神解构古代神话（第十一章）

"谁有证据证明神庙真的存在？"范闲依然还保留着现代人的实证精神。

费介傲然道："四大宗师之一的苦荷国师，只不过偶得神庙垂青，便成为大陆上的绝世强者，这难道不足以证明。"

"也许苦荷吃了很多兴奋剂，然后找神庙来当借口。"范闲扁扁嘴。

"……另外，兴奋剂是什么？"

"就是一种大补的药，类似于仙丹什么……肯定是补过头了，不然他头发怎么掉光了。"

> 要点：范闲用"实证精神/兴奋剂"等现代概念无厘头吐槽古代神庙信仰；费介一脸懵的反差是庆余年招牌幽默；对话自然、不刻意搞笑。

## 5. 反差萌：萌系主角 × 重口味情节（第七章）

坟坑中一片污臭，一个漂亮干净的小男孩戴着个大口罩，他小小的双手正从一具半腐的尸体里往外拖出粘成一团的肠子。

这个场景很恐怖，很可怕，范闲觉得自己的第二次人生依然凄惨。

> 要点：可爱男孩干恐怖解剖事，用冷静白描 + 末尾自嘲收束；环境极简（"坟坑中一片污臭"一笔带过），重心在人物动作与心理反差。

## 仿写自检清单

- [ ] 第三人称限知锁主角，内心用"主角觉得/心想"心理流，不转"我"、不用"心中"明标
- [ ] 保留穿越者/现代人参照系（用现代事物类比古代），但不过度玩梗
- [ ] 纯现代白话（什么/看/知道/我们/如果/已经），无古风硬拽
- [ ] 对话占比约两成，台词带现代口语+吐槽感，标签用"道/说道"
- [ ] 破折号可适度、顿号分号极省、感叹号克制（<1/千字）
- [ ] 环境极简（<1%字数），重心在对话与心理
- [ ] 黑色幽默用冷静笔调写重口味/荒诞，制造反差萌
- [ ] 章末心理收束或反差画面定格，绝不留作者求票PS括号
- [ ] 无系统流、无网文戏剧化套话
