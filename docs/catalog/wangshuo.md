# 🎭 王朔风格 · 技能画像

> 共 2 个技能 ｜ 返回 [README](../../README.md)

王朔「起初」系列以京味口语重写上古与汉武：现代词、文言引文与全球神话并置，对白不加引号，史实与戏仿并行。《纪年》是第一人称汉武帝，《竹书》是第三人称拟汉学人，两本声口不同。

### 《起初·纪年》（王朔） · `xin-wangshuo-style-qichu-jinian`

- **风格画像**：第一人称「我」＝汉武帝；私人回忆用京味口语，朝会、诏书与战报切换成「上」的公文声口。汉武编年体，全书 78 节以裸数字分节，无章名。
- **核心特征**：对白零引号、标签只用「说」、一段内多轮来回；厚段落（均值 108.6 字、>400 字占 3.7%）；现代官僚词（总提/前指/动员/保密/编制）与文言诏令、军报体三层混写；「马迁注」随文夹注；军报句短名词密，写完立刻切回口语吐槽。
- **情绪基调**：冷幽默与官场黑色喜剧为表，战争机器的沉重为底；收尾多是一句冷话，不设悬念、不抒情、不升华。

### 《起初·竹书》（王朔） · `xin-wangshuo-style-qichu-zhushu`

- **风格画像**：第三人称＋拟汉学人叙述，从五帝、夏、商、周写到周穆王西行；46 节编年，节以裸数字标记，节长 203–18,544 字。
- **核心特征**：伪考据（李鼻约按/长枞有言/音转/异本/讹记）、古歌四言＋白话翻译、京味对白零引号、旅行志式环境（11.5% 段 / 21.5% 字）、全球神话互文（西王母/阿玛/麦什耶/《传道书》）。
- **情绪基调**：苍凉、荒诞、文明挽歌；幽默是学术黑话＋跨时代吐槽，不是《纪年》的官场喜剧。
