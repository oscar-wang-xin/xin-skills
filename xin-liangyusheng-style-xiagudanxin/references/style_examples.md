# 《侠骨丹心》代表段落档案

引文均为清洗后样本的**逐字原文**，取自梁羽生《侠骨丹心》前二十回（1967 年 10 月 5 日–1969 年 6 月 20 日连载于香港《新晚报·天方夜谭》，繁体底本经整体转简）。为存真貌，源文件的零星 OCR 错字未作改动，**仅在段末以「注」标明，仿写时不继承**。

---

## 1. 卷首诗 + 引诗 + 写景 + 人物（第 1 回开篇）

全书唯一一次「诗→引诗→写景→人物」的四段式开场。先四句卷首诗并署名出处，紧接着一段写景，然后**在第二段就把「这是谁」交代得干干净净**，第四段才进入人物内心。第 2 回起全部改走「零前奏直接切入」，此式只用于开卷。

```
陶潜诗喜说荆轲，想见停云发浩歌。
吟到恩仇心事涌，江湖侠骨恐无多。
——龚定盦己未杂诗
空山寂寂，鸟鸣嘤嘤，猿响寒岩树，鸟鸣山更幽。在猿啼鸟语之中，却忽有空谷足音，踏破了荒山的寂静。
这是一个披着满身风沙的少年，他是武当派掌门人雷震子的关门徒弟秦元浩。此时正从险窄崎岖的徂徕山道上经过。
徂徕山是在山东西北部的一座名山，在泰安县之南，与泰安之北的泰山遥遥相对。山虽然不算很高，但因无甚出产，野兽也不多，山上却是少有人家。秦元浩踏进徂徕山之后，一直就是踽踽独行，没有碰见过一个路人。
虽然是踽踽独行，寂寞无伴，但秦元浩的心中却是热烘烘的。他听着山中的鸟语，似乎是在一唱一和，心里想道：“古诗说‘嘤其鸣矣，求其友声。’鸟鸣嘤嘤，自古以来，就当作是求友之声，我这次到东平县去，正是广交天下英豪的好机会。”
```

写法要点：**书名在卷首诗里点题（「江湖侠骨恐无多」正对书名《侠骨丹心》）**；引诗必署出处（`——龚定盦己未杂诗`）；写景只占一段，且立刻转成人物处境（空谷足音 → 披着满身风沙的少年）；地名必交代方位、物产、人烟，这是梁羽生的「地图癖」。

## 2. 回末定场诗公式（第 1 回末）——整个样本 20/20 回同款

末段台词后紧接「**正是：**」（**同一段内，不换段**），随后两句对仗诗独占一段，最后「**欲知后事如何？请听下回分解。**」独占一段。注意是「**请听**」不是「请看」——这一字之差正是《侠骨丹心》与同作者后期作品的分界标记。悬念停在「新变数刚起」那一刻，不停在打斗高潮。

```
封妙嫦道：“江海天既有大侠之称，想来该是个奸人吧？文叔叔，你怎的和他结了冤仇？”这一问把文道庄问得甚是尴尬。正是：
可怜小儿女，尚未解机心。
欲知后事如何？请听下回分解。
```

## 3. 全知视角跳出剧情补叙 + 跨书括注考据（第 2 回）

「原来」（全样本 215 次＝10.8 次／回）是梁羽生的补叙引子：上一回留的悬念，本回开头由叙述者一次性把前情、因果、门派谱系全铺开，再用一个**圆括号**指路到自己别的作品去。**这不是赘笔，是这本书的呼吸节奏**，砍掉就不再是梁羽生。

```
文道庄本人在中原那几年，跟他叔父一同做了清廷的鹰爪，他叔父和金世遗结下深仇，他自己则和金世遗的徒弟江海天结了深仇，事情由于他要娶大魔头欧阳仲和的女儿欧阳婉，当时欧阳婉正在私恋江海天，不愿嫁给文道庄。拜堂之日，私逃出去。而江海天在那日也恰巧来到她家，和欧阳婉的一个师兄把文道庄打得重伤，原来欧阳婉私恋江海天，而她那个师兄又是私恋她的。重伤文道庄的其实是他，江海天只是帮手。不过，欧阳婉这个师兄当场自杀，文道庄遂把所有的帐都算在江海天身上。二十余年过去，江海天、欧阳婉均已另嫁另娶，文道庄回转了无名岛亦已娶妻生子。但这二十多年前的旧恨，他几乎是念念不忘。（文廷璧叔侄与金世遗师徒结怨之事，事详拙著《冰河洗剑录》）
```

括注考据全书仅 6 处（圆括号共 8 个字符），全部作「名词解释」或「跨书指路」：

- `（文廷璧叔侄与金世遗师徒结怨之事，事详拙著《冰河洗剑录》）`
- `（事详《冰河洗剑录》）`
- `（事详《风雷震九州》）`×2

## 4. 一段之内多人来回（第 1 回）

**这是本书对话排版的核心形态，也是与网文差别最大的一处。** 全样本「纯对话独立成段」仅 0.4%（10/2595 段），「含 1 处发言段」52.9%、「含 2 处以上发言段」16.1%。同一段里可以走三四个来回，说话人标签连写、台词连排，不换段。

```
封子超打了个哈哈说道：“我在此隐居，极少与外人来往。江大侠虽是闻名天下，我可没有去拜访过他。料想江大侠也不会知道我这个山野鄙人，他怎会发请帖给我。”文道庄笑道：“我是个无名小卒，更不会有江家的请帖了。”
秦元浩道：“两位是世外高人，可敬，可敬！好，我敬两位一杯。”他自己说过不能再喝的，如今却又要和人家干杯了。封妙嫦看看他的面色不对，说道：“秦少侠看来你是当真醉了，不能再喝啦！”封子超横她一眼，说道：“嫦儿，你怎的如此不懂礼貌，只有劝客人喝酒，哪有阻客人喝酒的。”
```

**另有约 8 处是原书的特殊排印**：一段里前一句台词不闭合引号，直接接下一个说话人，例如 `封妙嫦道：“文叔叔，爹爹，你们为什么要弄醉了他了，封子超恼道：“大人说话，你不要多事！”`。这是原书排印特征，**须原样保留，不得强行补引号**。

## 5. 谐音括注 + 机锋斗口（第 8 回）

金逐流是梁羽生笔下最「痞」的一类主角（偷儿出身、嘴上不饶人），本书的幽默主要靠**双关 + 谐音括注 + 互相抬杠**，而不是靠叙述者讲笑话。这段「送钟（终）」是全样本最典型的一次：

```
金逐流对他有了怀疑，对他更增鄙视，于是摇了摇头，说道：“我不要和你分赃，但毁尸灭迹的事我也是不干的！”
那书生哈哈笑道：“毁尸灭迹，这说法倒很新鲜，但这是有毒的尸体，毁了他有何不可？不过，你不愿意干我当然也不便勉强你，只有我自己干啦。”说罢，提起了那口铜钟，走出破庙。
金逐流心想：“且看他有什么本领可以毁掉这口大钟。”心念未已，那书生已是回头向他打了个招呼，说道：“还有半个时辰才会天亮，你不急于走吧？不要你毁尸灭迹，只请你送钟（终）。”金逐流听他说得风趣，不觉笑道：“好，只是给钟送终，不是给你送钟，那我倒是乐意的。”
```

写法要点：谐音用**圆括号当场标注本字**（`送钟（终）`）；机锋要**在两三个来回内自己再翻一层**（「只是给钟送终，不是给你送钟」）；拟声与笑声都极省（全样本「哈哈」119 次、「嘻嘻」15 次、「嘿嘿」2 次、「格格」3 次）。

## 6. 打斗：声到人到 + 招式 + 拟声 + 结果（第 14 回）

打斗靠「**招式名 + 部位 + 拟声 + 后果**」四件套推进，招式名一律用引号夹住（`“横云断峰”`、`“弯弓射雕”`、`“横扫六合”`、`“乱披风”`），不写抽象的力量感，也不用破折号渲染。拟声只用「的一声」这种短音（全样本 25 处「的X声」，破折号全样本仅 11 处）。

```
何老大眼看女儿受辱，明知打不过对方的三个人，也不能不拼一拼了。就在“公子爷”的扇头敲下之际，何老大喝道：“天下有这样横蛮霸道的请客的么？”声到人到，五指如钩，倏地就抓着了那个“公子爷”的扇头，“公子爷”用力一夺，“啪”的一声，折扇断为两截。
那“公子爷”也是好生了得，折扇被夺，立即便是反手一掌。他虽是在受挫之余，这一掌的力道还当真不弱，只听得掌风呼呼，打得沙飞石走。
双掌相交，“公子爷”只觉得自己这一掌好似打到棉花堆里似的，软绵绵的毫不受力。忽听得有人失声叫道：“不好！”话犹未了只听得“咋嚓”一声，这“公子爷”的一条左臂已是给何老大拗脱了。
```

> 注：本段末「咋嚓」疑为「咔嚓」，源文件 5 处一律作「咋嚓」，属版本用字，存疑未改。仿写用「咔嚓」。

## 7. 写景：掌故铺陈 + 建筑细节 + 人物动线（第 9 回）

纯景物段全样本只占 0.8%，但一到新场景就写得实。手法是**先讲这块地的来历与掌故，再从人物脚下带出建筑与花木**，最后落到人物的心情或盘算上，绝不做静态航拍。

```
快活林在苏州北郊，本来是元末割据江淮的吴王张士诚的离宫，张士诚与朱元璋逐鹿中原，长江一战，兵败投江。张士诚死后，这座离宫被当作逆产变卖，到了清初，数度易主，到了一个富商手中，将它建成一个园林式的旅店，专门招待富商大贾、公子王孙。租金比普通的客店昂贵百倍，但若不是预先租下，临时投宿还往往会额满见遗。
金逐流在陈家的时候，曾经和陈天宇谈过想到苏州游玩。这快活林就是陈天宇介绍给他的。金逐流身上还有在路上偷来的金银，有心到快活林去把钱花光。
金逐流进入快活林，迎面便是一条曲折的长廊，壁上嵌有一块块的历代书法法帖，只是园林主人不知保护，已现出剥落模糊的痕迹。出了长廊，两旁林木掩映，花木竹石，构成假山、荷池、幽谷、敞轩，哪里像个旅店，简直就是王侯住宅。金逐流很是喜欢，心里想道：“快活林果然名不虚传，只不知我有没有福气在这里快活快活？”
```

写景三件套：**地名 + 掌故**（张士诚离宫 → 变卖 → 清初易主 → 富商改建）、**建筑与草木的实指**（长廊、法帖、假山、荷池、幽谷、敞轩）、**人物的目光与盘算收口**（「只不知我有没有福气在这里快活快活？」）。

## 8. 内心独白：必带标签，允许长篇自问自答（第 11 回）

内心活动**一律有中介标签**，绝不写无中介的意识流。主要形态是「**心里想道**」（126 次，6.3／回），其次是「心中想道」13 次、「心道」39 次、「心想」78 次。允许整段都是自问自答，甚至允许叙述者替人物做判断。

```
金逐流目送着史红英的背影，渐远渐隐，终于看不见了，金逐流心里自思：“不知她是去什么地方？恐怕就是去找李敦了吧。”忽地想起了史红英所说的那几句话：“咱们萍水相逢，我用不着知道你的行止……
可是史红英的影子仍然盘旋在他的脑海，挥不去，抹不掉。她那明艳绝俗的姿容，超卓不凡的本领，落落大方的态度，都给金逐流的印象是太深刻了！金逐流在自嘲自笑之后，自己都不禁觉得奇怪起来……
金逐流发觉了自己心底的秘密，惘惘前行！自思自责：“朋友妻，不可欺。李敦和你好歹也算得是个朋友了，为什么你老是在想着他的意中人？金逐流呀金逐流，你应该做个光明磊落的男子汉，心里怎能有……
```

写法要点：自问用问号收尾（全样本问号 5.5／千字 > 感叹号 3.9／千字）；**点名叫自己**（「金逐流呀金逐流」）；情绪出口是自责与惘然，不是嘶吼。

## 9. 幽默调剂：莲花落 + 斗口（第 3 回开篇）

本书开篇第一句就是一段自编「莲花落」，用**市井俗曲**把主角的痞气一次立住，再用台词互相噎。梁羽生的幽默是「人物自带的」，不是叙述者插科打诨。

```
这小叫化唱的是一支自编的“莲花落”：“一朵一枝莲花，有个小子是大傻瓜，他把老虎当外婆，他把毒酒当香茶。见了人家的好闺女，就糊里糊涂的闯了进去啦！呷呀呀！酒不醉人人自醉，这小子要拜倒在石榴裙下，自己先醉成了一团烂泥巴。呷呀呀，一朵一枝莲花，这个小子真真是个大傻瓜，咿呀呀，哈，哈，哈！”
秦元浩一看，这小叫化蓬首垢面，但穿的一身衣囊，虽是遍打补丁，却颇干净，看来也是二十岁左右的年纪，和他不相上下。秦元浩听他的歌词，似乎就是嘲讽自己的，不禁跳了起来，叫道：“你是谁？你唱这个是什么意思？”
那小叫化咧嘴露齿地笑道：“什么意思？你自己应该明白。你怎么到这儿来的，你别做梦啦！你咬着指头儿做什么？”
```

> 注：本段源文件作「篷首垢面」，已还原为「蓬首垢面」；「一身衣囊」疑为「一身衣裳」、「遍打补丁」疑为「打满补丁」，存疑未改。

## 10. 回末钩子的另一路：把主角推到「刚被人暗算」那一刻（第 20 回末）

钩子不是拳头，是人。这一回停在全书中段最狠的一处转折——盟友刚被点穴、匕首刚出手，诗就接上来了。注意末句台词与「正是：」压在同一段内。

```
史红英因见厉南星已经飞驰而去，戒备不免稍微松懈。哪知史白都趁着她说话分神之际，突然就抢了她的匕首，把那柄匕首向厉南星掷去。史红英失声惊呼，但“啊呀”两字刚刚叫出，史白都已是点了她的穴道。正是：
清者自清浊自浊，虽然兄妹也成仇。
欲知后事如何？请听下回分解。
```

写法要点：末段**先给一个「以为没事了」的松懈镜头**（「戒备不免稍微松懈」），再在一句之内完成反手（抢匕首、掷出、点穴），然后用钩子封口。全样本 20 回的钩子全部按此结构收束，无一例外。
