# 《我不是戏神》 代表性段落样本

> 以下片段摘自清洗后的前 20 章正文，用于写作时对照语感。**仅供文风参照，禁止复述或改写其中情节。**

---

## 样本 1 · 开篇冷启动（第1章 戏鬼回家 · 章首）

**用途**：对白+雷雨冷开场、逗号处断段、拟声独立成段、省略号迟疑。

```
“我……是谁？”

轰隆——

苍白的雷光闪过如墨云层，

雨流狂落，神怒般的雷雨浇灌在泥泞大地，涟漪层叠的水洼倒影中，一道朱红色的人影支离破碎。

那是位披着大红戏袍的少年，他好似醉酒般踉跄淌过满地泥泞，宽大的袖摆在狂风中飘舞，戏袍表面的泥沙被雨水冲落，那抹似血的鲜红在黑夜中触目惊心。

“别吵了……别吵了！”

“都给我住嘴！”

“我马上就要想起来了……马上……就要想起来了……”
```

**要点**：
- 首句一句对白，独段，5 字。
- 拟声词 `轰隆——` 独段。
- 一句话在逗号处拆成两段（"苍白的雷光闪过如墨云层，"）。
- 环境与人同句，不做独立景物段。
- 对白里密集省略号制造崩溃感。

## 样本 2 · 系统面板钩子（第2章 我们在看着你 · 章末）

**用途**：日常物异化、【】系统文字独立成段、破折号收尾。

```
他刚蹲下身，便愣在原地。

只见地上的水渍竟然开始自动滑动，就像是在他的对面，蹲了一个看不见的身影，用指尖蘸着水，在地上书写着什么。

下一刻，透明的水渍肉眼可见的化作血红，一段扭曲而诡异的文字，勾勒在陈伶身前。

——【我们在看着你】。
```

**要点**：
- 恐怖来自日常物（水渍）的异化，不靠血腥。
- 系统文字用 `【】` 包裹，破折号前置，独立成段收尾。
- 末句 9 字，短句定格。

## 样本 3 · 短句爆破 + 拟声（第3章 灾厄 · 章末）

**用途**：动作高潮收尾、拟声叠加、省略号悬停、句号单字爆破。

```
盘上的指针猛的抖动起来！

指针在不同颜色的区域疯狂横扫，刺耳的吱嘎声从仪器内部传出，韩蒙瞳孔骤然收缩，下意识的松开灾厄指针！

砰——！！

无数零件崩碎在半空，锋利的指针断口擦过韩蒙脸颊，顿时留下一道猩红血迹！

灾厄指针……

炸了。
```

**要点**：
- `砰——！！` 拟声叠破折号与双叹号，独段。
- `灾厄指针……` / `炸了。` 两句各独段，省略号悬停后单字爆破。
- 恐惧反应公式：`瞳孔骤然收缩`。

## 样本 4 · 冷幽默对话（第5章 灰界 · 章末）

**用途**：一捧一逗式相声对话、信息差反转、三字台词定格。

```
陈伶拿筷子的手微微一顿，犹豫片刻后，还是开口道：

“赵叔……你知道赵乙为什么学习这么差吗？”

“啊？为什么？”

陈伶正欲说些什么，却又陷入沉默许久，还是摇了摇头，“算了赵叔，当我没提过吧……我答应过他要保密的。”

“别啊！”

赵叔心跳都加快了，他顺手给陈伶加了个卤蛋，急的直挠头，

“阿伶啊，我知道你是小乙的好朋友，但有些事情……我，我这个当爹的也得知道一点吧？……”

见赵叔如此急迫的询问，陈伶微微动容，他纠结片刻，像是下定了决心，

“赵叔你说的对，作为朋友，我也实在不忍心看赵乙这么堕落下去了……”

“堕，堕落？他究竟怎么了？”

“他谈恋爱了。”

“啊？”赵叔一愣，“这小子还有这魅力？”

陈伶面不改色的啃了口油条，淡淡吐出三个字：

“跟男的。”
```

**要点**：
- 十余回合短交锋，每句 3～15 字。
- 铺垫十几个回合，答案只用三字。
- 长台词在逗号处拆段（"赵叔心跳都加快了，他顺手给陈伶加了个卤蛋，急的直挠头，"）。
- 末句独段，三字定格。

## 样本 5 · 恐怖动作 + 系统面板（第10章 “观众” · 中段）

**用途**：拟声独段、日常物异化、叠词诡异笑声、系统数值插播。

```
“嘻嘻。”

诡异的轻笑声从陈伶背后响起。

下一刻，陈坛手中的餐刀凭空消失，取而代之的，是一张细长的红色纸片。

双瞳涣散的陈伶，将嘴中的斧头与菜刀全部咀嚼吞咽，直勾勾的看着陈坛，他缓步向前，机械而沙哑的重复同一句话：

“爸，我饿。”

简单的三个字，却让陈坛的头皮一阵发麻！
```

```
李秀春茫然的低下头，才发现门把手已经消失了……不，不光是门把手，整个大门都变成了红纸上的画像，从三维变成了二维。

她没法打开一扇画在纸上的门。

“嘻嘻嘻嘻……”

密密麻麻的声音从四面八方堆叠，仿佛此刻的屋子里，已经站满了无数个看不见的身影……他们注视着两人，猩红眼眸中满是戏谑。

红色纸片在李秀春的周围飞舞，恍惚中她看到一张张诡异的面孔，

她不断的尖叫，后退着，眼眸中只剩下最纯粹的恐惧。

终于，她的双眸一翻，整个人瘫软在地，失去知觉……

【观众期待值-1】

【当前期待值：16%】
```

**要点**：
- `“嘻嘻。”` `“嘻嘻嘻嘻……”` 叠词笑声独段，是本书恐怖标志。
- 三维→二维的异化比喻，是本书招牌恐怖手法。
- 逗号处断段（"恍惚中她看到一张张诡异的面孔，"）。
- 系统面板两行连排独立成段，插在场景收束后。

## 样本 6 · 温情静谧收束（第15章 是你！ · 章末）

**用途**：情绪落点、极短对白、反差式冷幽默旁白、静谧收尾。

```
陈伶怔了许久，发现他看不穿这个少年在想什么，他轻轻弯下腰，用手摸了摸他的头发。

“累了，就睡吧……哥在旁边守着你。”

原本温馨的家，已经被开出两个大洞，客厅更是破碎不堪，若是有小偷和盗贼路过，不顺手拿点什么真是对不起自己的职业。

陈宴回到那张熟悉的床上，默默的在被子中蜷缩成一团。陈伶走到他的身边，后背倚靠着断垣残壁，缓缓坐下。

透过破碎的屋顶，他能看到无尽的蓝色极光在黑夜中飘舞，好似轻柔缎带覆盖天穹，这是陈伶第一次安静的观赏这个世界的极光，好像看到它们的一瞬间，心中所有的杂念都消失了，只剩下永恒的平静。

“哥，你冷吗？”陈宴的声音从被子里传来。

“不冷。”

“哦……”

陈宴不再说话，许久之后，只剩下均匀的呼吸声萦绕在陈伶耳边。

不知过了多久，陈伶的双眸也逐渐闭起……

他睡着了。
```

**要点**：
- 温情不煽情：一个动作（摸头）+ 两句对白（"不冷。"/"哦……"）。
- 反差式冷幽默旁白插在悲凉场景中（"小偷和盗贼……对不起自己的职业"）。
- 环境段承担情绪功能，仍夹在叙事中，不独立成段。
- 末句 `他睡着了。` 四字独段，静谧收束。

## 样本 7 · 招式宣言式台词（第10章 “观众” · 章末）

**用途**：执法者登场、仪式感台词、破折号断句。

```
总长，韩蒙。”

他一只手夹着烟，另一只手从腰间掏出一柄漆黑的手枪，拇指拉下保险，领域中的砂石微微震颤起来，冥冥中一缕杀机，骤然锁定红纸怪物！

他双唇轻启，话语间仿佛带着某种法则的韵律，

“我秉持人类文明之正义……”

“审判你死亡。”
```

**要点**：
- 动作铺排 → 台词分两句独段，第二句四字定格。
- 招式名以台词形式落地，随后才在正文用 `【审判】` 标记。
- 台词前的逗号断段（"话语间仿佛带着某种法则的韵律，"）制造仪式感停顿。
