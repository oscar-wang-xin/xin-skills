# 文风锁定技能：《没钱修什么仙》（熊狼狗）

> 本包基于《没钱修什么仙》前 20 章（约 7.7 万字）清洗样本 + 全本 247 万字对照量化生成。所有硬规则均有全本计数背书。仿写时严格照"硬规则"与"十维指纹"执行。

## 一、作者与作品基底

- **作者**：熊狼狗（起点硬核修仙/凡人流代表，《食物链顶端的男人》《我的星球要有光》同作者路数）
- **题材**：**现代都市 + 科学修仙**（灵气复苏背景下的"修仙学科化"）：主角张羽穿越/重生到现代，修仙被十大宗门标准化成可量化的学科体系（法力点、境界分数、道心等级），没钱只能靠科学方法卷。非系统流、非面板升级、非网游体。
- **语域底色**：纯现代白话骨架 + 修仙术语硬核层 + **科学量化叙述腔**（把修仙当物理/考试讲）。态判定 = 纯现代白话（态1）+ 硬核修仙。
- **非古风书**：B类现代体压倒（看471:瞧0、已经129:已然0、没有124:未曾0），别凹文言。

## 三、硬规则（仿写必须执行）

1. **疑问代词统一"幺"拼写**：只用「什幺 / 怎幺 / 为什幺」，禁用「什么 / 怎么 / 为什么」。全本比值 ∞（什幺2943:什么8、怎幺1545:怎么2）。身份证级硬规则。
2. **单字语气词用"吗"**（全本2254），不用"么"。
3. **对话用纯直角引号「」**，不用全角" "。全本「」26121 vs 全角" "0。
4. **高频内心独白用"心中/心道"转述**（心中1.54/千）：主角心理活动直接以"张羽心中想到/心中叹道/心中暗骂"引出，这是本书最显眼特征（和捞尸人零内心戏相反）。
5. **硬核修仙体系 + 科学量化腔**：写境界/法力/道心时做标准化描述（"链气境界突破到筑基，法力要求60点以上，上限100点""法力检测精确到小数点后一位""仙道科目650分占150分"）。把修仙当学科/考试讲，不写玄乎感悟。
6. **零系统流**：不写面板/属性栏/升级提示/任务系统（系统71/面板4/升级95均极少量且非系统流义）。是传统修仙被现代制度化，不是网游。
7. **"说话"优于"讲话"**：说话422:讲话11（38:1）；"何况"优于"况且"：何况89:况且1（89:1）。

## 四、词汇修辞规范

- **只用**：什幺/怎幺/为什幺、吗、说话、何况、心中/心道（内心）、筑基/法力/金丹/元婴/道心/周天/境界/链气（修仙术语）。
- **禁用**：什么/怎么/为什么、讲话、么（单字）、系统/面板/升级/属性栏（系统流）。
- **中性可混**：便/就（便5680:就11290，用"就"为主）、咱们/我们（用"我们"）、若是/如果（用"如果"）、喝道/喊道（喝道67:喊道41近均，皆可）。
- **量化修辞**：用数据/标准/分数做喻体，忌文艺虚写。

## 五、句式与节奏

- 段长 20–50 字为主，逗号密铺；对话独立成段占比高（22.5%）。
- 节奏靠"认知反转"推进（原身记忆/科学方法打破修仙常识），不靠猛地/忽然炸点。
- 内心独白段常接动作（"张羽没有回应，心中却是一阵哀叹"）。

## 六、对话体系

- 标签"道"绝对主导（314次），辅以"说道/笑道/问道/奇道/怒道/喝道"。
- 对话内容常带修仙术语与学科味（"练气境作为仙道第一境，基础打多牢决定未来高度"）。
- 多 POV 但主角张羽限知为主。

## 七、标点规范

- 对话「」配对；省略号可用（全本0.86/千）；破折号少用（0.54/千）；顿号正常（2.40/千）。
- 问号密度偏高（4.56/千），多内心诘问外化。

## 八、视角与叙事

- **第三人称限知 + 高频内心独白**：以"心中/心道"转述主角心理（心中1.54/千），这是和捞尸人（零内心戏）最显眼的分野。
- 世界构建靠"十大宗门标准化体系" info-dump 自然融入叙事，不单独开设定章。

## 九、题材特征

- 现代都市（高中/面试/贷款/兼职）+ 灵气复苏修仙学科化；主角"没钱"靠科学方法逆袭。
- 修仙术语体系化：链气→筑基→金丹→元婴，法力/道心/周天/境界可量化。
- 冲突来自"贫穷+科学思维 vs 修仙资源垄断"，爽点在用物理/数据破解修仙玄学。
