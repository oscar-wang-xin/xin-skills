# 《不死帝师》代表段落样本

> 以下片段摘自清洗后的前20章纯净正文，供仿写时对照语感、分段与节奏使用。
> 使用规则：只学句式、分段、节奏与口吻，不得复述剧情。

## 1. 开篇：台词直接入场 + 系统面板（第1章）

```
“呸呸呸！”

洁白的月光撒在漆黑的大地上，一个年轻人正狂吐嘴里的泥土。

“说好的金丝楠木千年不腐，这才几年就变成渣了。”

“该死的李瘸子，居然敢拿假货骗我。”

吐干净了嘴里的泥土，陈长生活动了一下有些僵硬的四肢。

“系统，十年时间已经到了吗？”

“回宿主，十年沉睡已经结束，属性点已到账。”

听到系统的回答，陈长生看向了脑海中的面板。

【宿主：陈长生】

【力量：1】

【速度：1】

【防御：1】
```

**要点**：首句是拟声叹词独立成段；设定（沉睡十年、系统、属性点）不用旁白解释，全部拆进对话与短段，6 个短段交代完系统规则；面板用 `【】` 条目式，每条独立成段。

---

## 2. 设定释放：短段拆条 + 口语化推演（第1章）

```
没错，陈长生正是根正苗红的穿越者。

而他所拥有的系统不是什么签到系统，也不是什么屌炸天的无敌系统，只是“平平无奇”长生系统。

只要陈长生沉睡，就会获得相应的寿命和属性点。

不过沉睡时间也是有限制的，那就是不得超过寿命上限。

而且陈长生已经活过的寿命，在沉睡之后又会重新充能。

也就是说，假如陈长生活了八十年之后沉睡。

哪怕只是沉睡一天，醒来之后拥有的寿命将会是八十年零一天，而不是只有一天寿命。
```

**要点**：一条规则一段；用"也就是说，假如……"做口语化推演，避免说明文腔；规则讲解控制在 6 段内。

---

## 3. 情绪：克制外化，不抒情（第1章）

```
听到这话，陈长生愣了一下。

随后释怀的笑了，只不过这笑中带着几分苦涩。

沉睡十年，这对于自己来说是一个很短的时间。

可是对念慈来说，十年太漫长了，人生又能有几个十年呢？

当初分开的时候，自己和念慈都是二十岁。

十年之后，自己还是二十岁的样子，可念慈已经三十岁了。
```

**要点**：虐点用"笑了笑 + 几分苦涩"外化，随后用一组短句做时间对比（十年／二十岁／三十岁），不写一个"心痛""苦涩涌上心头"之类的抽象词。

---

## 4. 对话交锋：一问一答短来回（第4章）

```
看着低头不敢看自己的李念生，陈长生咂了咂嘴，说道。

“你真的想去吗？”

“想。”

“为了什么？”

听到这话，李念生的手不由紧了紧，然后轻声说道。

“为了长生。”

四个字轻飘飘的从李念生嘴里说出，但是这四个字却重如千钧。

因为只有得长生，才能永伴“长生”。
```

**要点**：一轮对话拆成 4 段，最短台词一个字成段；动作神态前置（"咂了咂嘴，说道。"）；台词后接一句短评（"重如千钧"）+ 一句点题（"永伴'长生'"）。

---

## 5. 反差口吻：对外谄媚，对内吐槽（第4章）

```
“哎呀！仙人光临寒舍，真是令寒舍蓬荜生辉呀！”

陈长生谄媚的向门口的女子行着大礼，那表现的样子和镇上的居民没什么两样。

然而面对陈长生的谄媚，门口的女子露出了丝丝嫌弃的表情。

……

陈长生的声音在棺材铺里回荡，可是店里除了冷冰冰的棺材，再也没有其他东西了。

“看样子那个老女人是真的走了。”

“会飞了不起呀！”

“小爷睡个千八百年照样可以飞，你最好别动念生的坏心思，不然小爷把你家祖坟都给挖干净。”

……

“三十年走不到，小爷不能走五十年吗？”

“我什么都不多，就是时间多。”
```

**要点**：同一章内两套口吻切换——人前谄媚客套，人后市井吐槽；爽点落在"时间多"而非"实力强"。

---

## 6. 职业细节 + 数字具象（第6章）

```
擦去血污，将散碎的皮肉缝好。

褪去残破的衣物，换上一件崭新的寿衣。

陈长生慢条斯理的替面前的尸体整理遗容，每一个步骤都做的一丝不苟，极为认真。

半个时辰之后，死者的样貌已经大致还原了，就连那些散落在周围的牙齿也被陈长生一一找齐。

做好一切，陈长生右手一拍腰间的兽皮袋。

一具上好的棺材就出现在眼前。

尸身放入棺材，陈长生开始用罗盘寻找着周围的风水宝地。

挖土刨坑，抬棺下葬，这些事情哪怕有小和尚在一旁辅助，陈长生也足足忙了两个时辰。
```

**要点**：职业流程拆成短句并列（擦去／褪去／放入／挖土刨坑／抬棺下葬）；用具体时长（半个时辰、两个时辰）与具体物件（罗盘、兽皮袋、牙齿）制造质感，不用形容词堆砌。

---

## 7. 时间快进：一笔带过（第6章、第7章）

```
三个月很快就过去了，陈长生在这三个月以来几乎是足不出户。

……

岁月悠悠，二十年时间转瞬而逝。
```

**要点**：时间跳跃只用一句话，独立成段，不做过程描写。

---

## 8. 章末钩子：认知反转（第2章）

```
“不是不给你买糖葫芦，实在是你那牙齿不能再吃糖葫芦了。”

“改天我带你去买......”

“念慈是我娘的小名。”

陈长生的话还没说完就被李念生打断了，而这句话也让陈长生放下了手里的碗。
```

**要点**：钩子放在最后两句，用一句身份揭示（"念慈是我娘的小名"）反转读者认知；末句回到主角动作（"放下了手里的碗"）留白。

---

## 9. 章末钩子：台词爆点（第17章）

```
“这个神秘的存在没有人知道他的名字，只知道他叫......”

“送葬人！”
```

**要点**：用省略号吊一句，再用一个名词独立成段引爆；这是本书最强的章末钩子形态，仅在关键节点使用。

---

## 10. 动作场面：短句快切（第19章）

```
“噗！”

一口心头血吐出，陈长生瞬间化为一道血色流光消失在天边。

而那两个在后面追赶的妖族修士也傻眼了。

因为他们从来没想过，一个金丹中期会使用这么高明的遁术。

“大哥，现在怎么办？”

“啪！”

其中一名金丹修士刚开口，就被他的同伴狠狠扇了一巴掌。
```

**要点**：战斗不写招式拆解，用拟声词独立成段（"噗！""啪！"）+ 一句结果 + 一句旁人反应；战斗篇幅压缩在几段内，重点在人物反应与吐槽。
