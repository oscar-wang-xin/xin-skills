# 《大道朝天》风格范例摘录

> 以下段落均摘自样本前 20 章原文，用于直观展示文风特征。仅作风格参考，不涉及剧情复述。

## 一、开篇：古典诗词题记 + 留白 + 直接切入

（全书仅第一章有此题记，非每章通例）

```
四大从来都遍满，此间风水何疑。故应为我发新诗。幽花香涧谷，寒藻舞沦漪。借与玉川生两腋，天仙未必相思。还凭流水送人归。层巅余落日，草露已沾衣。

（苏轼，临江仙，风水洞作，以为题记。）

……

……

朝天大陆南方，一片青山绵延数千里，数道。

阴三的尸体倒在地上。

她推开房门，走了出去。
```

**特征**：题记后用两行省略号留白，随即以极短句直接切入动作，无前奏。

## 二、对话 + 神态分开写（非表情化标签）

```
孟师看着她，神情温和了些许，说道："腊月不错。"

说完这句话，一道剑光破空而起，他的身影已然消失。

……

……

"师姐。"

"赵师姐。"

青山宗弟子们向少女围了过来，脸上满是仰慕、敬爱之情。
```

**特征**：神情/动作与台词拆成独立分句；"说道"不带"笑/怒"等修饰；对话可独立成段。

## 三、动作场面：留白胜于渲染

```
忽然，天地变色，十余道闪电撕裂碧空，数十团天雷轰向孤峰！

那些蕴藏着天地之威的雷电未能触着峰顶，便被斩成了碎片，化作了青烟。

因为孤峰里生出一道剑光。

没有人知道这一剑与先前的承天剑究竟谁更强。

不要说这位孟师，就是三千里外的那些大物也看不出来。

孤峰上出现的那道剑光看起来没有任何威力。

那就是一道剑，简单极了，很随意地斩向天空。

天雷却遇之而灭。

剑光继续向上。

嘶的一声轻响。

湛蓝的天空上多出了一道极细的裂口。
```

**特征**：短段碎句、逗号流水、拟声"嘶的一声轻响"、不堆形容词；以极简白描写磅礴一剑。

## 四、主角死神感 + 冷幽默反差

```
白衣少年站在石床前，看着那人沉默不语，不知道在想什么。

不知道过了多长时间，他终于说话了。

"真……烦。"

他的声音很干净，却有些发涩，语速非常缓慢，似乎很少说话。
```

```
他盘膝坐下，闭眼开始静思修行，显得特别自然。

但下一刻他便睁开了眼睛，茫然想道，入门口诀是什么来着？
```

**特征**：古老存在的绝对冷静 × 重生后"入门口诀是什么来着"的呆萌反差，是本书幽默核心。

## 五、冷峻智性台词

```
白衣少年说道："切断。"

世间任何事物，都有薄弱处。

他最擅长的便是找到那些薄弱处，然后让其断开。

比如法宝、比如山峰，或者别的什么。
```

```
柳十岁挠挠头，心想那您平日里天天睡觉，又是在做什么呢？

井九似乎知道他心里在想什么，说道："我在推演今后三千年。"
```

**特征**：台词短、信息密度高、带俯视众生的从容；不用长解释。

## 六、章末钩子（疑问/信息预告收束）

```
如临大敌，三千里禁，那是因为今天青山宗即将迎来千年里最重要的一件大事。

景阳师叔祖要飞升了。
```

```
"像我这样的人，居然也会无聊？"

井九感知着这种从来没有体会过的情绪，有些不确定地想着："像我这样的人，居然也会无聊？"
```

**特征**：章末落句号（信息预告）或问号（内心疑问），极少感叹号；不喊"未完待续"。

## 七、环境：设定性陈述，不工笔

```
青山有九峰，隐在云雾中。

天光峰乃是祖峰，掌门居所。

两忘峰是第二峰，青山宗最强的年轻弟子都在其间修剑。
```

```
石门样式简单，上面布满青苔，自有古意，横匾上隐约可以看到南松亭三字。
```

**特征**：一两句带过，交代世界结构，不铺陈景物。
